# DearBaby (디어베이비)

> 말로 전하는 사랑, AI가 완성하는 우리 아기 첫 번째 책

임산부가 말하기만 하면 AI가 그 기록을 아름다운 이야기로 엮어 세상에 하나뿐인 아기 첫 번째 책을 만들어주는 서비스입니다.

## 주요 기능

- **음성 일기 기록**: 말하기만 하면 AI가 자동으로 텍스트로 변환
- **매일 다른 질문 알림**: 임신 주차별로 의미 있는 질문을 매일 제공
- **AI 편집 & 서사 구성**: 흩어진 기록을 하나의 이야기로 엮어주는 AI
- **실물 책 제작**: 세상에 하나뿐인 우리 아기 첫 번째 선물
