# PRD-003: AI 편집 & 서사 구성

## 개요

사용자가 흩어진 기록들을 AI가 하나의 아름다운 이야기로 엮어주는 기능이다. 개별 기록의 단편적인 내용을 시간순으로 정리하고, 감성적인 서사로 재구성하여 아기에게 전하는 편지와 같은 이야기를 만든다.

## 제공 가치

- **V-001 (감정 보존)**: AI가 기록 속 감정을 살려 서사로 보존한다
- **V-003 (서사적 의미 부여)**: 흩어진 기록을 하나의 완성된 이야기로 구성한다
- **V-004 (음성-텍스트 자동 변환)**: AI가 텍스트를 서사 형태로 재가공한다

## Acceptance Criteria

### AC-003-01: AI 서사 생성

- **설명**: 축적된 기록을 기반으로 AI가 서사를 자동 생성한다
- **달성 가치**: V-003
- **조건**:
  - 일정 기간의 기록이 쌓이면 AI 서사 생성을 요청할 수 있다
  - AI가 기록을 시간순으로 정리하고 서사적 흐름으로 재구성한다
  - 생성된 서사는 아기에게 전하는 편지 형식으로 작성된다

### AC-003-02: 서사 미리보기

- **설명**: AI가 생성한 서사를 미리보기로 확인할 수 있다
- **달성 가치**: V-001
- **조건**:
  - 생성된 서사를 책 형태의 미리보기로 확인할 수 있다
  - 월별 또는 주차별로 서사 구간을 나누어 볼 수 있다

### AC-003-03: 서사 편집

- **설명**: 사용자가 AI 생성 서사를 수정할 수 있다
- **달성 가치**: V-001, V-003
- **조건**:
  - AI가 생성한 텍스트를 사용자가 직접 수정할 수 있다
  - 수정 후 저장하면 최종 서사로 확정된다
  - 원본 기록은 별도로 보존된다

### AC-003-04: 사진 첨부

- **설명**: 서사에 사진을 첨부하여 이야기를 풍성하게 만들 수 있다
- **달성 가치**: V-001
- **조건**:
  - 기록 또는 서사에 사진을 첨부할 수 있다
  - 초음파 사진, 일상 사진 등을 추가할 수 있다
  - 사진에 캡션을 입력할 수 있다
