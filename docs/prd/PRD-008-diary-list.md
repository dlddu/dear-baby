# PRD-008: 일기 탭 — 일기 목록 화면

## 개요

사용자가 자신이 작성한 과거 일기를 시간 흐름에 따라 다시 볼 수 있는 화면이다.
하단 네비게이션의 **일기 탭**(PRD-007 AC-007-10의 4번 탭)을 탭하면 진입한다.

홈 화면(PRD-007)이 "오늘 새로운 일기를 시작하는 진입로"라면,
일기 탭은 "지금까지 쌓아온 일기를 다시 만나는 공간"이다.
이 두 화면이 분리되어 있어야 사용자가 "쓰기" 와 "다시 보기" 를 명확히 구분하고,
누적된 일기가 한 권의 책처럼 시간 순으로 펼쳐지는 감각을 얻는다.

본 PRD는 일기 탭의 **MVP 범위**만 정의한다:
**(a) 목록 표시 · (b) 활성 아이 기준 필터링 · (c) 상세 진입 · (d) 빈 상태**.
편집/삭제(CRUD), 검색, 정렬 옵션, 페이지네이션, 날짜 점프, 다중 선택 등은
[후속 검토 항목](#후속-검토-항목)으로 분리한다.

## 제공 가치

- **V-001 (감정 보존)**: 시간이 흐른 뒤에도 과거의 감정·미디어·맥락을 다시 만날 수 있게 하여, 일기를 "남긴 뒤 잊히는 데이터" 가 아닌 "꺼내 볼 수 있는 기억" 으로 보존한다
- **V-002 (기록의 부담 제거)**: 자신이 이미 얼마나 일기를 남겼는지 시각적으로 확인하게 하여, "꾸준히 해왔다" 는 자기 효능감을 강화하고 다음 기록을 향한 심리적 진입 장벽을 낮춘다

## Acceptance Criteria

### AC-008-01: 일기 목록 — 시간순 그룹 표시

- **설명**: 사용자의 일기가 작성된 시간 순으로 정렬되어, 임신 주차(또는 양육 개월) 단위로 그룹화되어 표시된다
- **달성 가치**: V-001, V-002
- **조건**:
  - 일기 탭 진입 시 최신 일기가 화면 상단에 위치하고, 아래로 갈수록 오래된 일기가 표시된다 (역시간순)
  - 임신 모드: 일기가 **임신 주차** 기준으로 그룹화된다 (예: `28주차`, `27주차` ...)
  - 양육자 모드: 일기가 **개월수** 기준으로 그룹화된다 (예: `D+3개월`, `D+2개월` ...)
  - 같은 그룹 안에서는 작성 일자 역순으로 정렬된다
  - 그룹 헤더는 sticky 형태로 스크롤 중에도 현재 위치한 그룹이 화면 상단에 고정된다 (선택, 디자인 단계에서 확정)
  - 같은 날 작성된 여러 일기는 시간 역순으로 모두 별도 카드로 나열된다 (일자 단위 머지 없음)

### AC-008-02: 일기 카드 — 표시 정보

- **설명**: 목록의 각 카드는 사용자가 일기 내용을 다시 보지 않아도 식별 가능하도록 핵심 정보를 한 줄로 요약한다
- **달성 가치**: V-001
- **조건**:
  - 카드 1행: **작성 날짜**(예: `5/12 (월)`) + 미디어 유형 아이콘(🎤 음성 / 📷 사진 / 🎬 영상)
  - 카드 2행: **본문 미리보기 텍스트** (1~2줄, 말줄임표 처리)
  - 미디어가 첨부된 일기는 PRD-005 AC-005-07의 시각 구분 규칙을 따른다 (대표 썸네일은 디자인 단계에서 확정)
  - 일기 본문이 없고 미디어만 있는 경우, 미리보기 자리에 미디어 종류 설명을 표시한다 (예: `음성 1건 · 사진 2장`)

### AC-008-03: 활성 아이 기준 필터링

- **설명**: 다자녀 사용자의 경우, 일기 목록은 현재 활성 아이의 일기만 표시한다
- **달성 가치**: V-001
- **조건**:
  - PRD-006 AC-006-09 의 활성 아이 컨텍스트를 그대로 따른다
  - 활성 아이가 변경되면 일기 목록 전체가 즉시 갱신된다 (재진입 불필요)
  - 화면 상단에 활성 아이의 이름/태명이 표시되어 "지금 누구의 일기를 보고 있는지" 가 시각적으로 명확하다
  - 단일 아이 사용자(Case A 단일·Case C 단일)는 아이 전환 UI 없이 단일 컨텍스트로 표시된다

### AC-008-04: 일기 상세 화면 진입

- **설명**: 사용자가 일기 카드를 탭하면 해당 일기의 전체 내용을 볼 수 있는 상세 화면으로 이동한다
- **달성 가치**: V-001
- **조건**:
  - 카드를 탭하면 일기 상세 화면으로 전환된다
  - 상세 화면에서는 전체 본문 텍스트, 첨부된 모든 미디어(사진·영상·음성 원본), 작성 일시가 표시된다
  - 상세 화면에서 뒤로 가기 동작 시 목록의 동일 스크롤 위치로 복귀한다
  - 상세 화면의 구체적 레이아웃은 본 PRD 범위 밖이며 [후속 검토 항목](#후속-검토-항목)으로 분리한다

### AC-008-05: 빈 상태 — 일기가 없을 때

- **설명**: 활성 아이의 일기가 0건인 경우, 첫 일기로 유도하는 빈 상태 화면을 표시한다
- **달성 가치**: V-002
- **조건**:
  - 일러스트(또는 아이콘)와 짧은 안내 카피를 표시한다
  - **홈으로 가기** CTA 버튼이 제공되며, 탭하면 홈 탭(PRD-007)으로 이동한다
  - "검색해도 결과가 없을 때" 가 아닌 **활성 아이의 일기가 진짜 0건일 때** 만 빈 상태가 노출된다 (검색은 본 MVP 범위 밖)
  - 빈 상태 화면에서도 하단 네비게이션 바는 그대로 표시된다 (AC-007-10)

## PRD-001 AC-001-05 와의 관계

PRD-001 AC-001-05 "기록 목록 조회" 는 음성 일기 PRD에서 *부수적으로* 다루어진 목록 동작이다. 본 PRD-008 이 일기 목록 화면의 **정식 소유자**이며, AC-001-05 의 다음 요건이 본 PRD 의 AC 로 흡수·확장되었다:

| PRD-001 AC-001-05 조건 | PRD-008 흡수 위치 |
|---|---|
| 주차별로 기록 목록을 확인 | AC-008-01 |
| 각 기록에 날짜와 미리보기 텍스트 | AC-008-02 |
| 기록을 탭하면 전체 내용을 볼 수 있다 | AC-008-04 |

PRD-001 AC-001-05 의 라벨 "기록 탭" 은 **일기 탭**(PRD-007 AC-007-10 / mockup 라벨과 일치)으로 통일된다. 자세한 통일 결정은 `docs/glossary.md` 의 "탭 / 화면 용어" 섹션 참조.

PRD-005 AC-005-07 "미디어 포함 기록 목록 표시" 의 시각 구분 규칙은 본 PRD 의 AC-008-02 에서 그대로 참조한다.

## 후속 검토 항목

본 PRD-008 은 MVP 최소 범위만 다루며, 다음 항목은 별도의 후속 PRD 또는 본 PRD 의 추가 AC 로 다룬다.

- **CRUD**: 일기 편집·삭제 (현재 PRD-001 은 작성 후 편집 동작을 명세하지 않음)
- **상세 화면 레이아웃**: 본문·미디어 배치, 액션(공유·하트·삭제) 위치
- **검색**: 본문 텍스트 / 날짜 / 태그 기반 검색
- **날짜 점프**: 캘린더 진입으로 특정 일자/주차로 빠르게 이동
- **정렬 옵션**: 역시간순 외 정순, 미디어 유무, 길이 기준 등
- **페이지네이션 / 무한 스크롤** 정책 (현재는 단순 목록 가정)
- **다자녀 통합 보기**: 전체 아이의 일기를 한 목록에서 보는 옵션
- **빈 상태의 도움말**: 첫 일기 작성을 돕는 튜토리얼 진입 여부
- **그룹 헤더 sticky** 적용 여부 (디자인 단계 확정)
- **그룹 단위**: 임신 모드에서 주차 외 월 단위 그룹화 옵션 (장기 누적 시)
