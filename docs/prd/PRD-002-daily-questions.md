# PRD-002: 매일 다른 질문 알림

## 개요

임신 주차에 맞는 의미 있는 질문을 매일 제공하여 사용자가 기록할 소재를 자연스럽게 떠올릴 수 있도록 돕는 기능이다. "오늘의 질문"을 통해 기록의 방향을 제시하고, 기록 습관을 형성한다.

## 제공 가치

- **V-001 (감정 보존)**: 주차별 맞춤 질문으로 그 시기에만 느낄 수 있는 감정을 포착한다
- **V-002 (기록의 부담 제거)**: "무엇을 기록할지" 고민하는 부담을 질문이 대신 해결한다
- **V-005 (임신 주차별 맞춤 질문)**: 임신 주차에 따라 의미 있는 질문을 매일 제공한다

## Acceptance Criteria

### AC-002-01: 오늘의 질문 표시

- **설명**: 홈 화면에 오늘의 질문이 표시된다
- **달성 가치**: V-005
- **조건**:
  - 홈 화면에서 오늘의 질문 카드가 보인다
  - 현재 임신 주차 정보가 함께 표시된다
  - 질문에 대한 짧은 안내 문구가 포함된다

### AC-002-02: 임신 주차별 질문 매칭

- **설명**: 사용자의 임신 주차에 맞는 질문이 자동으로 선택된다
- **달성 가치**: V-005, V-001
- **조건**:
  - 사용자의 출산 예정일 기반으로 현재 임신 주차를 계산한다
  - 해당 주차에 적합한 질문 풀에서 매일 새로운 질문을 제공한다
  - 같은 질문이 반복되지 않는다

### AC-002-03: 질문에서 기록으로 연결

- **설명**: 질문을 보고 바로 해당 질문에 대한 기록을 시작할 수 있다
- **달성 가치**: V-002
- **조건**:
  - 질문 카드에서 바로 음성 기록 또는 텍스트 기록을 시작할 수 있다
  - 기록 시 해당 질문이 함께 저장된다

### AC-002-04: 질문 알림 발송

- **설명**: 매일 정해진 시간에 오늘의 질문을 푸시 알림으로 보낸다
- **달성 가치**: V-002
- **조건**:
  - 사용자가 설정한 시간에 푸시 알림이 발송된다
  - 알림을 탭하면 해당 질문 화면으로 이동한다
  - 알림 시간을 사용자가 변경할 수 있다
