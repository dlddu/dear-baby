# PRD-005: 기록 미디어 통합

## 개요

기록 작성 시 사진, 동영상, 음성 메모를 자연스럽게 첨부할 수 있는 기능이다. 기록 작성 화면 하단에 미디어 첨부 버튼 그룹(사진, 영상, 음성)이 위치하며, 첨부된 미디어는 텍스트 아래에 썸네일 목록으로 표시된다. 메신저 앱과 유사한 하단 첨부 방식으로, 기록 흐름을 끊지 않고 미디어를 추가할 수 있다.

## 제공 가치

- **V-001 (감정 보존)**: 사진, 영상, 음성은 텍스트로 표현하기 어려운 감정의 결을 그대로 보존한다
- **V-002 (기록의 부담 제거)**: 하단 첨부 방식으로 기록 흐름을 끊지 않고 한 번의 탭으로 미디어를 추가한다
- **V-007 (멀티미디어 감정 표현)**: 다양한 형태의 미디어로 임신 기간의 순간을 풍성하게 기록한다

## Acceptance Criteria

### AC-005-01: 사진 촬영 첨부

- **설명**: 기록 작성 중 카메라로 사진을 촬영하여 첨부할 수 있다
- **달성 가치**: V-001, V-007
- **조건**:
  - 기록 작성 화면 하단에 카메라 버튼이 있다
  - 버튼을 탭하면 카메라가 실행된다
  - 촬영한 사진이 기록에 썸네일로 표시된다

### AC-005-02: 갤러리 사진 첨부

- **설명**: 기록 작성 중 갤러리에서 사진을 선택하여 첨부할 수 있다
- **달성 가치**: V-001, V-007
- **조건**:
  - 기록 작성 화면 하단에 갤러리 버튼이 있다
  - 갤러리에서 여러 장의 사진을 동시에 선택할 수 있다
  - 선택한 사진들이 기록에 썸네일 목록으로 표시된다

### AC-005-03: 영상 촬영 첨부

- **설명**: 기록 작성 중 영상을 촬영하여 첨부할 수 있다
- **달성 가치**: V-001, V-007
- **조건**:
  - 기록 작성 화면 하단에 영상 촬영 버튼이 있다
  - 버튼을 탭하면 영상 촬영 모드가 실행된다
  - 촬영한 영상이 썸네일과 재생 시간과 함께 표시된다

### AC-005-04: 갤러리 영상 첨부

- **설명**: 기록 작성 중 갤러리에서 영상을 선택하여 첨부할 수 있다
- **달성 가치**: V-001, V-007
- **조건**:
  - 갤러리에서 영상을 선택할 수 있다
  - 선택한 영상이 썸네일과 재생 시간과 함께 표시된다

### AC-005-05: 음성 메모 첨부

- **설명**: 음성 녹음 원본을 재생 가능한 음성 메모로 기록에 첨부할 수 있다
- **달성 가치**: V-001, V-002, V-007
- **조건**:
  - 음성 녹음 후 텍스트 변환이 완료되면 '음성 원본도 저장' 옵션이 표시된다
  - 옵션을 선택하면 음성 원본이 재생 가능한 음성 메모로 기록에 첨부된다
  - 첨부된 음성 메모를 탭하면 재생할 수 있다

### AC-005-06: 미디어 미리보기 및 관리

- **설명**: 첨부된 미디어를 관리할 수 있다
- **달성 가치**: V-002
- **조건**:
  - 첨부된 미디어를 탭하면 전체 화면으로 볼 수 있다
  - 미디어를 삭제할 수 있다
  - 미디어에 캡션을 입력할 수 있다

### AC-005-07: 미디어 포함 기록 목록 표시

- **설명**: 기록 목록에서 미디어가 포함된 기록을 시각적으로 구분할 수 있다
- **달성 가치**: V-001
- **조건**:
  - 미디어가 포함된 기록에 미디어 유형 아이콘(사진/영상/음성)이 표시된다
  - 대표 썸네일이 기록 미리보기에 함께 표시된다

### AC-005-08: 미디어 AI 서사 연동

- **설명**: 기록에 첨부된 미디어가 AI 서사 생성 시 자동으로 포함된다
- **달성 가치**: V-001, V-003, V-007
- **조건**:
  - AI 서사 생성 시 기록에 첨부된 미디어가 자동으로 서사에 포함된다
  - 서사 미리보기에서 미디어가 텍스트와 함께 표시된다
  - 서사 편집 시 포함된 미디어를 제외하거나 순서를 변경할 수 있다 (PRD-003 AC-003-04 참조)
