# PRD-007: 홈 화면 구성

## 개요

디어베이비의 메인 진입 화면으로, 사용자가 앱을 열 때마다 가장 먼저 만나는 화면이다.
"꾸준히 기록한다"는 핵심 가치를 지탱하기 위해 **오늘의 질문 카드**를 중심에 배치하고,
주변을 ① 활성 아이 컨텍스트(헤더), ② 책 진행도, ③ 타인 기록 피드, ④ 하단 네비게이션으로 구성한다.

본 PRD는 홈 화면을 구성하는 **시각적·구조적 요소**와 **요소 간 상호작용**을 정의한다.
기록 자체의 동작(음성 변환·편집 등)은 [PRD-001](PRD-001-voice-diary.md),
질문 매칭 규칙은 [PRD-002](PRD-002-daily-questions.md),
다자녀 아이 전환의 데이터 모델은 [PRD-006](PRD-006-onboarding-cases.md)에서 다룬다.
본 PRD는 그것들을 한 화면에 어떻게 배치·연결하는지를 정의한다.

## 제공 가치

- **V-001 (감정 보존)**: 매일 만나는 첫 화면에서 기록 진입점을 1탭 이내로 제공하여 그날의 감정을 놓치지 않게 한다
- **V-002 (기록의 부담 제거)**: "무엇을 기록할지" 질문이 먼저 제시되고, 다른 엄마들의 기록이 함께 보여 기록 동기가 자연스럽게 유발된다 (홈 피드 섹션의 명세·가치 연결(V-008)은 [PRD-009 AC-009-14](PRD-009-community-tab.md) 소관 — 2026-08-05 이관)
- **V-003 (서사적 의미 부여)**: 책 진행도(n/50) 표시로 매 기록이 하나의 책으로 모여간다는 서사를 매일 인지하게 한다
- **V-005 (아이 단계별 맞춤 질문)**: 헤더의 주차/D-day/개월수 자동 갱신으로 현재 단계가 시각적으로 드러난다. 본 PRD의 AC-007-01은 단계 **표기 형식**의 단일 소스이며, 단계가 질문 모델에 포함된다는 규정은 [PRD-002](PRD-002-daily-questions.md) 소관이다
- **V-006 (실물 책 완성품)**: 책 진행도가 50에 도달하면 CTA로 전환되어 책 제작 플로우로 자연스럽게 연결된다

## Acceptance Criteria

### AC-007-01: 헤더 — 활성 아이 컨텍스트 표시

- **설명**: 헤더에 현재 활성 아이의 이름(또는 태명·애칭)과 컨텍스트(임신 주차/D-day 또는 양육 개월수/나이)가 표시된다
- **달성 가치**: V-001, V-005
- **조건**:
  - 헤더 중앙에 활성 아이의 **이름/태명/애칭**이 표시된다
  - 프로필 사진 아래(이름 바로 아래)에 컨텍스트 정보가 표시된다
  - **임산부 모드**:
    - 출산 예정일까지의 잔여일이 **101일 이상**이면 `00주차` 형식으로 표시 (예: `28주차`)
    - 잔여일이 **100일 이하**가 되면 `D-00` 형식으로 표시 (예: `D-36`)
    - 주차/D-day는 시스템 날짜 기준으로 매일 자동 갱신된다 (계산 규칙은 [engineering/ENG-001-pregnancy-week-calc.md](../engineering/ENG-001-pregnancy-week-calc.md) 따름)
  - **양육자 모드**:
    - 생년월일 기준 누적 개월 수가 **12개월 이하**이면 `mm개월 (nn일째)` 형식으로 표시 (예: `5개월 (152일째)`)
    - **13개월 이상**이 되면 `nn살 (nn일째)` 형식으로 표시 (예: `2살 (430일째)`)
    - 컨텍스트는 시스템 날짜 기준으로 매일 자동 갱신된다
  - 활성 아이의 프로필 사진(임산부는 초음파, 양육자는 아이 사진, 미설정 시 기본 일러스트)이 함께 표시된다

### AC-007-02: 헤더 — 다자녀 아이 전환

- **설명**: 다자녀 사용자는 헤더의 좌우 화살표(◀ ▶)로 다른 아이의 홈 화면으로 전환할 수 있고, 화면 전체가 선택된 아이 기준으로 즉시 갱신된다
- **달성 가치**: V-001
- **참조**: [PRD-006 AC-006-08, AC-006-09](PRD-006-onboarding-cases.md) (아이 컨텍스트 데이터 모델)
- **조건**:
  - 아이가 **1명**인 경우: 좌우 화살표는 **비활성화** 상태(흐리거나 표시 안 됨)로 노출된다
  - 아이가 **2명 이상**인 경우: 좌우 화살표가 활성화된다
  - 화살표를 탭하면 다음/이전 아이의 컨텍스트로 전환된다
  - 전환 시 **헤더의 이름/주차/사진**, **오늘의 질문 카드의 프로필·질문 텍스트**, **책 진행도(n/50)** 가 선택된 아이 기준으로 즉시 갱신된다
  - 타인 기록 피드는 활성 아이와 무관한 영역이므로 갱신되지 않는다
  - (옵션) 아이가 2명 이상인 경우 좌우 스와이프 제스처로도 전환 가능하다 — 후속 검토

### AC-007-03: 헤더 — 알림 아이콘

- **설명**: 헤더 가장 우측에 알림 아이콘이 노출되며, 안 읽은 알림이 있으면 red dot이 표시된다
- **달성 가치**: V-002
- **조건**:
  - 헤더 가장 우측에 종 모양 알림 아이콘이 고정 노출된다
  - 안 읽은 알림이 1개 이상 있으면 아이콘 우상단에 **빨간 점(red dot)** 이 표시된다
  - 안 읽은 알림이 0개이면 red dot이 표시되지 않는다
  - 알림 아이콘을 탭하면 알림 목록 화면으로 이동한다

### AC-007-04: 오늘의 질문 카드 — 표시

- **설명**: 화면 메인 영역에 오늘의 질문이 아이 1인칭 시점의 말풍선으로 표시된다
- **달성 가치**: V-001, V-002, V-005
- **참조**: [PRD-002 AC-002-01, AC-002-02](PRD-002-daily-questions.md) (질문 매칭 규칙)
- **조건**:
  - 좌측 상단에 활성 아이의 **프로필 이미지**가 원형으로 표시된다
  - 프로필 이미지 아래에 **아이 이름/태명**과 **주차/개월수 정보** (AC-007-01 규칙과 동일)가 표시된다
  - 우측 상단에 **말풍선** 형태로 질문 텍스트가 표시된다
  - 질문 텍스트는 **아이 1인칭 시점**으로 작성된 문장이어야 한다 (예: "엄마, 오늘은 제가 ~ 했나요??")
  - 가능한 경우 말풍선의 꼬리가 좌측 프로필 이미지 방향을 향하도록 디자인한다
  - 질문은 대상 아이의 **단계(임신 주차 또는 생후 나이)** 에 매칭된 풀에서 선택된다 — 질문 모델과 매칭 규칙은 [PRD-002](PRD-002-daily-questions.md) 소관이며, 단계를 산출할 수 없는 경우 단계 표시 없이 공용 풀 질문이 노출된다 (PRD-002 AC-002-05)

### AC-007-05: 오늘의 질문 카드 — 다른 질문 보기

- **설명**: 사용자는 오늘 받은 질문이 마음에 들지 않으면 하루 최대 3개까지 다른 질문을 회전하며 확인할 수 있다
- **달성 가치**: V-002, V-005
- **조건**:
  - 말풍선 우측 하단에 **좌우 화살표 버튼**과 **`< n/3 >` 형식의 인덱스**가 표시된다
  - 우측 화살표를 탭하면 다음 질문으로 회전한다
  - 좌측 화살표를 탭하면 이전 질문으로 회전한다
  - **하루에 최대 3개**까지만 회전 가능하다 (4번째 탭은 무시되거나 비활성화)
  - 첫 번째 위치는 `1/3`으로 표시되고, 마지막 질문에 도달하면 우측 화살표가 비활성화된다
  - 회전된 질문 중 어떤 질문에 답하든 그 답변은 해당 질문과 함께 저장된다 (PRD-002 AC-002-03 참조)
  - 회전 상태는 당일 자정까지 유지되며, 다음 날 새로운 3개로 갱신된다

### AC-007-06: 오늘의 질문 카드 — 음성/텍스트 기록 진입

- **설명**: 말풍선 하단에 두 개의 기록 진입 버튼(음성/텍스트)이 표시되고, 탭하면 각각 음성 녹음 모달 또는 텍스트 입력 모달이 하단에서 올라온다
- **달성 가치**: V-001, V-002
- **참조**: [PRD-001 AC-001-01 (음성), AC-001-04 (텍스트)](PRD-001-voice-diary.md)
- **조건**:
  - 말풍선 하단에 두 버튼이 좌우로 나란히 배치된다:
    - 좌측: 🎙️ 마이크 아이콘 + **"목소리로 남기기"** 라벨
    - 우측: ✏️ 연필 아이콘 + **"글로 남기기"** 라벨
  - **목소리로 남기기** 탭 시:
    - 하단에서 음성 녹음 모달이 슬라이드 업으로 열린다
    - 모달에는 녹음 시작 버튼이 있다 (이후 흐름은 PRD-001 AC-001-01)
  - **글로 남기기** 탭 시:
    - 하단에서 텍스트 입력 모달이 슬라이드 업으로 열린다
    - 모달에는 빈 입력 영역이 노출된다 (이후 흐름은 PRD-001 AC-001-04)
  - 어느 버튼으로 진입하든 현재 표시된 질문(AC-007-05의 n번째 질문)이 답변에 함께 저장된다

### AC-007-07: 오늘의 질문 카드 — 책 진행도 표시

- **설명**: 오늘의 질문 카드 가장 하단에 책 생성 진행도가 표시되고, 누적 답변이 일정 수에 도달하면 "책 만들기" CTA로 교체된다
- **달성 가치**: V-002, V-003, V-006
- **참조**: [PRD-004 실물 책 제작](PRD-004-book-production.md)
- **조건**:
  - 기록 진입 버튼 아래에 다음 형식의 텍스트가 표시된다:
    - `아이에게 전해줄 책이 만들어지고 있어요 (?) (n/50)`
  - **`n`** 은 활성 아이 기준으로 사용자가 작성한 답변 수의 누적 카운트다
  - **`50`** 은 책 생성에 필요한 최소 기록 수 임계값이다 (초기 값, 후속 조정 가능)
  - **`(?)` 아이콘**을 탭하면 책 생성 관련 안내 모달이 열린다:
    - 모달 내용: 일정 수 이상의 기록이 쌓이면 AI가 자서전을 만들어주고, PDF로 평생 소장할 수 있다는 안내 (정확한 카피는 후속 작업)
  - **n이 50에 도달하면** 진행도 텍스트가 **"책 만들기" CTA 버튼**으로 교체된다
  - "책 만들기" 버튼을 탭하면 **자서전 탭**으로 이동한다
  - 다자녀인 경우 n은 활성 아이별로 독립적으로 카운트된다 (PRD-006 다자녀 컨텍스트 원칙)

### AC-007-08: 타인 기록 피드 — 카드 표시 *(PRD-009로 이관)*

- **설명**: 홈 하단 "다른 엄마들의 기록" 섹션의 명세는 [PRD-009 AC-009-14](PRD-009-community-tab.md)로 이관되었다 (2026-08-05). 화면 구조상 섹션 위치는 본 PRD의 화면 구조 다이어그램을 유지한다
- **이관 사유**: 커뮤니티 피드와 카드 구성·빈 상태·노출 규칙을 공유하므로, 명세의 단일 소스를 PRD-009로 통합

### AC-007-09: 타인 기록 피드 — 노출 로직 *(ENG로 이관)*

- **설명**: 피드 노출 로직(공개 상태 필터·정렬·본인 기록 처리)은 미확정 상태로 분리되어 엔지니어링 초안 [ENG-007](../engineering/ENG-007-community-feed-default-sort.md)·[ENG-008](../engineering/ENG-008-community-feed-exposure-pool.md)·[ENG-010](../engineering/ENG-010-community-feed-own-records.md)이 관리한다 (2026-08-05). 확정 시 재개발한다
- **이관 사유**: 정렬 기준·랜덤성·본인 기록 노출 여부가 모두 미결정이어서 AC(검증 가능 조건)로 성립하지 않음

### AC-007-10: 하단 네비게이션 바

- **설명**: 모든 탭에서 공통으로 노출되는 5개 탭의 고정 하단 네비게이션 바를 정의한다
- **달성 가치**: V-001, V-002, V-006
- **조건**:
  - 하단 네비게이션 바는 모든 탭에서 동일하게 노출된다 (홈, 자서전, 커뮤니티, 일기, 설정 어느 탭에서도)
  - 탭 순서와 역할은 다음과 같다:

    | 순서 | 탭 이름 | 설명 |
    |---|---|---|
    | 1 | 자서전 | 책 만드는 진행 상태와 제작 요청을 관리하는 탭. AC-007-07의 "책 만들기" CTA로 진입 가능 |
    | 2 | 커뮤니티 | 공개로 설정된 다른 사용자 기록 피드([PRD-009](PRD-009-community-tab.md)). AC-009-14의 ">더보기"로 진입 가능 |
    | 3 | 홈 | 메인 화면 (본 PRD가 다루는 화면) |
    | 4 | 일기 | 내 과거 기록 전체 조회 및 CRUD, 날짜 필터 기능 등 |
    | 5 | 설정 | 프로필, 아이 정보, 알림, 공개 기본값 등 앱 기본 설정 |

  - 현재 탭은 시각적으로 강조 표시된다 (선택 상태 디자인 토큰은 디자인 시스템 따름)
  - 홈 탭(3번)이 중앙에 위치하여 양손 엄지 접근성을 우선한다
