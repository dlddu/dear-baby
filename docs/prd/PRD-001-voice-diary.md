# PRD-001: 음성 일기 기록

## 개요

사용자가 음성으로 말하면 AI가 자동으로 텍스트로 변환하여 임신 일기를 기록하는 기능이다. 디어베이비의 핵심 입력 메커니즘으로, 타이핑 없이 말하기만 하면 기록이 완성된다.

## 제공 가치

- **V-001 (감정 보존)**: 음성에 담긴 감정과 뉘앙스를 텍스트로 보존하여 영구적 기록을 생성한다
- **V-002 (기록의 부담 제거)**: 타이핑 대신 말하기로 기록 진입 장벽을 낮춘다
- **V-004 (음성-텍스트 자동 변환)**: AI 기반 음성 인식으로 한국어 음성을 텍스트로 자동 변환한다

## Acceptance Criteria

### AC-001-01: 음성 녹음 시작 및 종료

- **설명**: 사용자가 녹음 버튼을 탭하여 음성 녹음을 시작하고 종료할 수 있다
- **달성 가치**: V-002
- **조건**:
  - 홈 화면에서 '음성으로 기록' 버튼이 명확히 보인다
  - 탭 한 번으로 녹음이 시작된다
  - 녹음 중 시각적 피드백(파형 등)이 제공된다
  - 탭 한 번으로 녹음이 종료된다

### AC-001-02: AI 음성-텍스트 변환

- **설명**: 녹음된 음성이 AI를 통해 자동으로 텍스트로 변환된다
- **달성 가치**: V-004, V-002
- **조건**:
  - 녹음 종료 후 텍스트 변환 결과를 표시한다
  - 한국어 음성을 정확하게 변환한다
  - 변환 중 로딩 상태를 표시한다
  - 변환 완료 후 음성 원본 저장 옵션을 제공한다 (PRD-005 AC-005-05 참조)

### AC-001-03: 변환 텍스트 편집

- **설명**: 사용자가 AI 변환 결과를 확인하고 편집할 수 있다
- **달성 가치**: V-001
- **조건**:
  - 변환된 텍스트를 사용자가 직접 수정할 수 있다
  - 편집 후 저장 버튼으로 최종 기록을 확정한다

### AC-001-04: 텍스트 직접 입력

- **설명**: 음성 대신 텍스트로 직접 기록을 작성할 수 있다
- **달성 가치**: V-001
- **조건**:
  - '텍스트로 작성' 버튼을 통해 텍스트 입력 모드로 전환할 수 있다
  - 텍스트로 작성한 기록도 음성 기록과 동일하게 저장된다

### AC-001-05: 기록 목록 조회

- **설명**: 사용자가 작성한 기록을 목록으로 확인할 수 있다
- **달성 가치**: V-001
- **조건**:
  - '기록' 탭에서 주차별로 기록 목록을 확인할 수 있다
  - 각 기록에 날짜와 미리보기 텍스트가 표시된다
  - 기록을 탭하면 전체 내용을 볼 수 있다
