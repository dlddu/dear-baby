# PRD-001: 음성 일기 기록

## 개요

사용자가 음성으로 말하면 AI가 자동으로 텍스트로 변환하여 임신 일기를 기록하는 기능이다. 디어베이비의 핵심 입력 메커니즘으로, 타이핑 없이 말하기만 하면 기록이 완성된다.

## 제공 가치

- **V-001 (감정 보존)**: 음성에 담긴 감정과 뉘앙스를 텍스트로 보존하여 영구적 기록을 생성한다
- **V-002 (기록의 부담 제거)**: 타이핑 대신 말하기로 기록 진입 장벽을 낮춘다
- **V-004 (음성-텍스트 자동 변환)**: AI 기반 음성 인식으로 한국어 음성을 텍스트로 자동 변환한다
- **V-008 (공감을 통한 연결)**: 작성 시점에 기록의 공개 여부를 선택할 수 있어, 원하는 기록만 커뮤니티로 이어진다

## Acceptance Criteria

### AC-001-01: 음성 녹음 시작 및 종료

- **설명**: 사용자가 녹음 버튼을 탭하여 음성 녹음을 시작하고 종료할 수 있다
- **달성 가치**: V-002
- **조건**:
  - 홈 화면에서 '음성으로 기록' 버튼이 명확히 보인다
  - 탭 한 번으로 녹음이 시작된다
  - 녹음 중 시각적 피드백(파형 등)이 제공된다
  - 탭 한 번으로 녹음이 종료된다

### AC-001-02: AI 음성-텍스트 변환

- **설명**: 녹음된 음성이 AI를 통해 자동으로 텍스트로 변환된다
- **달성 가치**: V-004, V-002
- **조건**:
  - 녹음 종료 후 텍스트 변환 결과를 표시한다
  - 한국어 음성을 정확하게 변환한다
  - 변환 중 로딩 상태를 표시한다
  - 변환 완료 후 음성 원본 저장 옵션을 제공한다 (PRD-005 AC-005-05 참조)

### AC-001-03: 변환 텍스트 편집

- **설명**: 사용자가 AI 변환 결과를 확인하고 편집할 수 있다
- **달성 가치**: V-001
- **조건**:
  - 변환된 텍스트를 사용자가 직접 수정할 수 있다
  - 편집 후 저장 버튼으로 최종 기록을 확정한다

### AC-001-04: 텍스트 직접 입력

- **설명**: 음성 대신 텍스트로 직접 기록을 작성할 수 있다
- **달성 가치**: V-001
- **조건**:
  - '텍스트로 작성' 버튼을 통해 텍스트 입력 모드로 전환할 수 있다
  - 텍스트로 작성한 기록도 음성 기록과 동일하게 저장된다

### AC-001-05: 기록 목록 조회

- **설명**: 사용자가 작성한 기록을 목록으로 확인할 수 있다
- **달성 가치**: V-001
- **조건**:
  - '기록' 탭에서 주차별로 기록 목록을 확인할 수 있다
  - 각 기록에 날짜와 미리보기 텍스트가 표시된다
  - 기록을 탭하면 전체 내용을 볼 수 있다

### AC-001-06: 작성 시점 공개/비공개 선택

- **설명**: 기록을 저장하는 시점에 해당 기록의 공개 여부를 선택할 수 있다
- **달성 가치**: V-008
- **참조**: [PRD-008 AC-008-05·07 (사후 변경)](PRD-008-diary-tab.md), [PRD-009 (커뮤니티 노출 의미)](PRD-009-community-tab.md)
- **조건**:
  - 기록 저장(확정) 화면에 공개/비공개 토글이 표시된다 (음성·텍스트 작성 모두 동일)
  - **기본값은 비공개**다
  - 선택한 값은 기록의 공개 상태로 저장되며, 공개 상태의 의미(커뮤니티 노출)는 PRD-009를 따른다
  - 저장 후 변경은 PRD-008 AC-008-05(편집 화면 토글)·AC-008-07(사후 전환)로 가능하다
  - 임시 저장 기록(AC-001-07)은 서버에 전송되지 않은 상태이므로 공개 여부 선택의 대상이 아니다

### AC-001-07: 임시 저장 — 업로드 전 로컬 보관

- **설명**: 작성이 중단되거나 업로드가 실패한 녹음은 기기에 임시 저장되어 유실되지 않는다
- **달성 가치**: V-001
- **조건**:
  - 녹음 종료 후 업로드 실패·중단(앱 종료, 네트워크 단절 포함) 시 오디오 파일과 메타데이터가 기기에 로컬 보관된다
  - 임시 저장 보관함 화면에서 보관된 항목을 확인하고, 업로드 재시도 또는 삭제할 수 있다
  - 임시 저장 기록은 서버에 전송되기 전 상태이며, 정식 기록이 아니므로 일기 목록·커뮤니티 어디에도 노출되지 않는다
  - 업로드가 성공하면 임시 저장 항목은 정식 기록으로 전환되고 보관함에서 제거된다
  - 구현 참조: `app/src/drafts/` (로컬 오디오 저장소), `app/app/drafts.tsx` (보관함 화면)
