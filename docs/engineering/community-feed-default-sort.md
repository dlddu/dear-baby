# 커뮤니티 피드 — 기본 정렬 (초안)

## 지위

**미확정 초안이다.** PRD-009 확정 과정에서 노출 로직을 AC 밖으로 분리하기로
결정(2026-08-05)했고, 그중 기본 정렬을 본 문서가 담는다. 아래 내용은 구현
착수를 위한 임의 초안이며, 제품 결정이 내려지면 본 문서를 확정(status 변경)하고
해당 구현을 재개발한다. 확정 전까지 이 초안을 근거로 한 구현은 정합성 판정의
대상이 아니다.

## 범위

- 커뮤니티 탭 피드(PRD-009 AC-009-02)와 홈 "다른 엄마들의 기록" 섹션
  (PRD-009 AC-009-14)의 **기본 정렬 축** 하나만 다룬다.
- 유사 시기 가중치는 [ENG-011](community-similar-stage-recommendation.md)이
  확정 정의하며, 본 문서의 기본 정렬 **위에** 적용된다.
- 노출 풀([ENG-008](community-feed-exposure-pool.md)) ·
  페이지네이션([ENG-009](community-feed-pagination.md)) ·
  본인 기록 노출([ENG-010](community-feed-own-records.md))은 각자의 문서에서
  다룬다 (한 번호 한 내용 원칙).

## 초안

이관 전 구 PRD-007 AC-007-09의 초안은 "공감(하트) 수 내림차순 + 새로고침 시
상위 풀 내 랜덤성"이었다. 본 초안은 이를 대체하는 새 임의안이며, 확정 시 두
안 중 택일하거나 제3안을 정의한다.

- 기본 정렬: **작성 시각 내림차순(최신순)**.
- 동률(동일 시각)은 record id 내림차순으로 안정 정렬.
- **인기순(공감 수) 정렬은 1차 런치 후순위**다. 이 항목은 PRD-009 하단
  "1차 런치 범위" 표에 있던 것을 이관해 온 것으로, 도입 시 본 문서에서 기본
  정렬과의 관계(토글 vs 대체)를 함께 정의한다.

## 열린 질문

- 최신순이 유사 시기 가중치(ENG-011)와 결합될 때의 최종 순위 함수
  (가중 점수식 vs 2단 정렬).
- 인기순 도입 시점과 하트 수 어뷰징 대응.
