# 커뮤니티 피드 — 페이지네이션 (초안)

## 지위

**미확정 초안이다.** PRD-009 확정 과정(2026-08-05)에서 노출 로직을 AC 밖으로
분리하며 신설했다. 제품 결정 시 확정하고 구현을 재개발한다.

## 범위

커뮤니티 탭 피드와 "같은 질문 답변 모아보기" 목록의 페이지 로딩 방식만 다룬다.
홈 "다른 엄마들의 기록" 섹션은 최대 3개 고정 노출이라(PRD-009 AC-009-14)
페이지네이션이 없다.

## 초안

- **커서 기반 무한 스크롤.** 커서는 `(정렬 키, record id)` 복합 — 오프셋
  방식은 피드 갱신 중 중복/누락이 생겨 배제.
- 페이지 크기 20. 하단 도달 시 다음 페이지 로드, 로딩 인디케이터 표시.
- 당겨서 새로고침 시 커서 초기화.
- 비공개 전환·삭제로 빠진 항목은 다음 페이지 조회에 자연 반영 (클라이언트
  보정 없음 — PRD-008 AC-008-07의 "다음 새로고침 시 사라진다"와 정합).

## 열린 질문

- 유사 시기 가중치(ENG-011)가 점수식으로 확정될 경우 커서 키 설계
  (점수는 시간에 따라 변해 커서로 부적합 — 스냅샷 점수 vs 2단 정렬 필요).
- 페이지 크기 20의 적정성 (실측 후 조정).
