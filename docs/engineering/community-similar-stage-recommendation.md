# 커뮤니티 — 유사 시기 추천 로직 (확정)

## 지위

**확정 문서다** (2026-08-05 제품 결정). PRD-009 AC-009-03은 상단 상태값
표시만 담고, "비슷한 시기 우선 노출"의 정의는 본 문서가 단일 소스다.

## 정의

"유사 시기"란 **열람자의 활성 아이 현재 단계**와 **기록의 작성 시점 단계**가
아래 반경 안에 있는 것을 말한다.

| 항목 | 확정 내용 |
|---|---|
| 반경 — 임산부 | 현재 임신 주차 기준 **±4주** |
| 반경 — 양육자 | 현재 생후 개월 수 기준 **±1개월** (주차 ±4주의 개월 매핑) |
| 케이스 경계 | **혼합 금지.** 임산부 열람자에게는 임신 시점 기록만, 양육자 열람자에게는 생후 시점 기록만 |
| 유사도 기준 시점 | 기록의 **작성 당시** 단계. 작성자의 현재 상태와 무관 (지금 30주차인 사용자가 20주차에 쓴 글은 20주차 콘텐츠) |
| 적용 강도 | **정렬 가중치.** 하드 필터가 아니며, 반경 밖 기록도 뒤 순위로 노출된다 |

## 세부 규칙

- **작성 시점 단계 산출**: 기록 작성일 + 대상 아이의 출산 예정일(임신) 또는
  생일(양육)로 계산한다. 계산식은 [ENG-001](pregnancy-week-calc.md) 준용.
  스냅샷 컬럼 저장 여부는 구현 재량이다 — 소급 계산이 항상 가능하므로 기존
  기록 백필은 불필요하다.
- **케이스 판정도 작성 당시 기준**: 출산한 사용자의 과거 임신 기록은 계속
  임산부 풀에 속한다. 작성 후 케이스가 바뀌어도 기록의 소속은 불변.
- **가중치 결합**: 기본 정렬([ENG-007](community-feed-default-sort.md), 초안)
  위에 얹는다. 반경 내 기록 그룹이 반경 밖 그룹보다 항상 앞서고, 그룹 내부는
  기본 정렬을 따른다 (2단 정렬). ENG-007 확정 시 점수식 통합 여부를 재검토할
  수 있으나, 본 문서의 반경·경계·기준 시점·강도 정의는 그와 무관하게 유지된다.
- **경계값**: 반경은 폐구간이다 (20주차 열람자 기준 16~24주차 작성 기록이
  반경 내).

## 적용처

- 커뮤니티 탭 피드 (PRD-009 AC-009-02·03)
- 홈 "다른 엄마들의 기록" 섹션 (PRD-009 AC-009-14)
- 같은 질문 답변 모아보기의 정렬 (PRD-009 AC-009-04)
