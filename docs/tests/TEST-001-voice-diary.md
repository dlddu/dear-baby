# TEST-001: 음성 일기 기록 테스트

## 대상 PRD

PRD-001: 음성 일기 기록

## 테스트 케이스

### TC-001-01: 음성 녹음 시작 및 종료 테스트

- **검증 대상**: AC-001-01
- **사전 조건**: 사용자가 로그인하고 홈 화면에 있다
- **테스트 단계**:
  1. 홈 화면에서 '음성으로 기록' 버튼을 확인한다
  2. 버튼을 탭하여 녹음을 시작한다
  3. 녹음 중 시각적 피드백이 표시되는지 확인한다
  4. 버튼을 다시 탭하여 녹음을 종료한다
- **기대 결과**: 녹음이 정상적으로 시작/종료되며, 녹음 중 시각적 피드백이 제공된다

### TC-001-02: AI 음성-텍스트 변환 테스트

- **검증 대상**: AC-001-02
- **사전 조건**: 음성 녹음이 완료된 상태
- **테스트 단계**:
  1. 녹음을 종료한다
  2. 변환 중 로딩 상태가 표시되는지 확인한다
  3. 변환 완료 후 텍스트 결과를 확인한다
  4. 한국어 음성이 정확하게 변환되었는지 확인한다
- **기대 결과**: 음성이 텍스트로 정확하게 변환되며, 변환 중 로딩 상태가 표시된다

### TC-001-03: 변환 텍스트 편집 테스트

- **검증 대상**: AC-001-03
- **사전 조건**: AI 음성-텍스트 변환이 완료된 상태
- **테스트 단계**:
  1. 변환된 텍스트를 탭하여 편집 모드로 진입한다
  2. 텍스트 내용을 수정한다
  3. 저장 버튼을 탭한다
- **기대 결과**: 텍스트 수정이 가능하며, 저장 후 수정된 내용이 반영된다

### TC-001-04: 텍스트 직접 입력 테스트

- **검증 대상**: AC-001-04
- **사전 조건**: 사용자가 로그인하고 홈 화면에 있다
- **테스트 단계**:
  1. '텍스트로 작성' 버튼을 탭한다
  2. 텍스트 입력 화면이 표시되는지 확인한다
  3. 텍스트를 입력하고 저장한다
- **기대 결과**: 텍스트 입력 모드로 전환되며, 작성한 기록이 음성 기록과 동일하게 저장된다

### TC-001-05: 기록 목록 조회 테스트

- **검증 대상**: AC-001-05
- **사전 조건**: 최소 1개의 기록이 저장된 상태
- **테스트 단계**:
  1. '기록' 탭을 탭한다
  2. 기록 목록이 표시되는지 확인한다
  3. 각 기록의 날짜와 미리보기 텍스트를 확인한다
  4. 기록을 탭하여 전체 내용을 확인한다
- **기대 결과**: 기록이 주차별로 정리되어 표시되며, 탭하면 전체 내용을 볼 수 있다

### TC-001-06: 작성 시점 공개/비공개 선택 테스트

- **검증 대상**: AC-001-06
- **사전 조건**: 로그인 및 온보딩 완료 상태
- **테스트 단계**:
  1. 기록 작성(음성 또는 텍스트)을 진행해 저장 화면까지 이동한다
  2. 공개/비공개 토글의 초기값이 **비공개**인지 확인한다
  3. 토글을 공개로 변경하지 않고 저장한 뒤, 기록 상세에서 상태가 비공개인지 확인한다
  4. 새 기록을 작성하며 토글을 공개로 변경해 저장하고, 상태가 공개로 저장되는지 확인한다
- **기대 결과**: 저장 화면에 공개 토글이 표시되고 기본값은 비공개이며, 선택한 값이 기록의 공개 상태로 저장된다

### TC-001-07: 임시 저장 보관·재시도 테스트

- **검증 대상**: AC-001-07
- **사전 조건**: 네트워크를 차단할 수 있는 테스트 환경
- **테스트 단계**:
  1. 네트워크를 차단한 상태에서 음성 녹음을 완료해 업로드를 실패시킨다
  2. 임시 저장 보관함 화면에 해당 항목이 나타나는지 확인한다
  3. 일기 목록에는 해당 항목이 나타나지 않는지 확인한다
  4. 네트워크를 복구하고 보관함에서 업로드를 재시도한다
  5. 업로드 성공 후 항목이 보관함에서 사라지고 정식 기록으로 목록에 나타나는지 확인한다
  6. (별건) 보관함에서 다른 항목을 삭제하면 목록에서 제거되는지 확인한다
- **기대 결과**: 업로드 실패 녹음이 기기에 보관되어 유실되지 않고, 재시도로 정식 기록 전환·보관함 제거가 이루어진다
