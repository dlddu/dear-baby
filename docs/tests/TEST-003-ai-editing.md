# TEST-003: AI 편집 & 서사 구성 테스트

## 대상 PRD

PRD-003: AI 편집 & 서사 구성

## 테스트 케이스

### TC-003-01: AI 서사 생성 테스트

- **검증 대상**: AC-003-01
- **사전 조건**: 일정 기간 동안 기록이 축적된 상태
- **테스트 단계**:
  1. AI 서사 생성 요청 버튼을 탭한다
  2. AI가 기록을 분석하고 서사를 생성하는 과정을 확인한다
  3. 생성된 서사가 시간순으로 정리되어 있는지 확인한다
  4. 서사가 아기에게 전하는 편지 형식으로 작성되었는지 확인한다
- **기대 결과**: 축적된 기록을 기반으로 시간순 서사가 편지 형식으로 생성된다

### TC-003-02: 서사 미리보기 테스트

- **검증 대상**: AC-003-02
- **사전 조건**: AI 서사가 생성된 상태
- **테스트 단계**:
  1. 생성된 서사의 미리보기 화면을 확인한다
  2. 책 형태의 레이아웃으로 표시되는지 확인한다
  3. 월별 또는 주차별 구간 나누기를 확인한다
- **기대 결과**: 생성된 서사가 책 형태의 미리보기로 구간별 확인 가능하다

### TC-003-03: 서사 편집 테스트

- **검증 대상**: AC-003-03
- **사전 조건**: AI 서사가 생성된 상태
- **테스트 단계**:
  1. 서사 텍스트를 탭하여 편집 모드로 진입한다
  2. 텍스트를 수정한다
  3. 저장 버튼을 탭한다
  4. 원본 기록이 별도로 보존되어 있는지 확인한다
- **기대 결과**: 서사 수정이 가능하며, 원본 기록은 별도로 보존된다

### TC-003-04: 미디어 서사 통합 테스트

- **검증 대상**: AC-003-04
- **사전 조건**: 미디어가 첨부된 기록이 존재하고, AI 서사가 생성된 상태
- **테스트 단계**:
  1. 서사에 기록에서 첨부된 미디어가 자동으로 포함되어 있는지 확인한다
  2. 서사 편집에서 추가 사진을 직접 첨부한다
  3. 서사에 포함된 미디어의 순서를 변경한다
  4. 불필요한 미디어를 서사에서 제외한다
  5. 미디어에 캡션을 입력한다
  6. 저장 후 변경 사항이 반영되었는지 확인한다
- **기대 결과**: 기록의 미디어가 서사에 자동 포함되며, 추가 첨부·순서 변경·제외·캡션 입력이 정상 동작한다
