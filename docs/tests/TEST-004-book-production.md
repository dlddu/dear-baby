# TEST-004: 실물 책 제작 테스트

## 대상 PRD

PRD-004: 실물 책 제작

## 테스트 케이스

### TC-004-01: 책 레이아웃 선택 테스트

- **검증 대상**: AC-004-01
- **사전 조건**: AI 서사가 완성된 상태
- **테스트 단계**:
  1. 책 제작 화면으로 이동한다
  2. 제공되는 디자인 템플릿 목록을 확인한다
  3. 표지 디자인을 선택한다
  4. 내지 레이아웃 미리보기를 확인한다
- **기대 결과**: 여러 디자인 템플릿 중 선택이 가능하며, 미리보기로 확인할 수 있다

### TC-004-02: 책 내용 구성 확인 테스트

- **검증 대상**: AC-004-02
- **사전 조건**: 레이아웃이 선택된 상태
- **테스트 단계**:
  1. 전체 페이지 미리보기를 확인한다
  2. 서사, 사진, 레이아웃이 통합되어 표시되는지 확인한다
  3. 내용을 수정한다
  4. 수정 사항이 반영되는지 확인한다
- **기대 결과**: 전체 책 내용을 미리보기로 확인할 수 있으며, 제작 전 수정이 가능하다

### TC-004-03: 제작 주문 및 결제 테스트

- **검증 대상**: AC-004-03
- **사전 조건**: 책 내용 확인이 완료된 상태
- **테스트 단계**:
  1. 책 사양(크기, 제본 방식)을 선택한다
  2. 배송 정보를 입력한다
  3. 결제 수단을 선택한다
  4. 결제를 진행한다
- **기대 결과**: 사양 선택, 배송 정보 입력, 결제가 정상적으로 완료된다

### TC-004-04: 제작 상태 추적 테스트

- **검증 대상**: AC-004-04
- **사전 조건**: 제작 주문이 완료된 상태
- **테스트 단계**:
  1. 마이 페이지에서 주문 내역을 확인한다
  2. 제작 진행 상태(접수 → 인쇄 → 제본 → 배송)를 확인한다
  3. 배송 추적 정보를 확인한다
  4. 제작 완료 알림이 도착하는지 확인한다
- **기대 결과**: 제작 상태를 단계별로 추적할 수 있으며, 완료 시 알림을 받는다
