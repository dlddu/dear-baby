# TEST-007: 홈 화면 구성 테스트

## 대상 PRD

[PRD-007: 홈 화면 구성](../prd/PRD-007-home-screen.md)

## 테스트 케이스

### TC-007-01-A: 임산부 — 28주차 헤더 표시

- **검증 대상**: AC-007-01
- **사전 조건**: 출산 예정일이 등록되어 잔여일이 101일 이상인 임산부 사용자
- **테스트 단계**:
  1. 홈 화면을 연다
  2. 헤더 중앙에 아이의 태명이 표시되는지 확인한다
  3. 프로필 사진 아래에 컨텍스트 텍스트가 표시되는지 확인한다
  4. 컨텍스트 텍스트가 `00주차` 형식인지 확인한다 (예: `28주차`)
- **기대 결과**: 헤더에 태명과 `00주차` 형식의 컨텍스트가 표시된다

### TC-007-01-B: 임산부 — D-day 표시 (잔여일 100일 이하)

- **검증 대상**: AC-007-01
- **사전 조건**: 출산 예정일까지의 잔여일이 100일 이하인 임산부 사용자
- **테스트 단계**:
  1. 홈 화면을 연다
  2. 컨텍스트 텍스트가 `D-NN` 형식인지 확인한다 (예: `D-36`)
  3. 시스템 날짜를 +1일로 변경(또는 다음 날 재진입)하여 D-day 값이 1 감소하는지 확인한다
- **기대 결과**: 컨텍스트가 `D-36` 형식으로 표시되고 매일 자동 갱신된다

### TC-007-01-C: 양육자 — 개월 수/나이 자동 분기

- **검증 대상**: AC-007-01
- **사전 조건**: 생년월일이 등록된 양육자 사용자
- **테스트 단계**:
  1. 생후 5개월 아이 컨텍스트로 홈을 연다 → `5개월 (152일째)` 형식 확인
  2. 생후 13개월 이상 아이 컨텍스트로 홈을 연다 → `1살 (XXX일째)` 형식 확인
- **기대 결과**: 12개월 이하는 `mm개월 (nn일째)`, 13개월 이상은 `nn살 (nn일째)` 형식으로 표시된다

### TC-007-02-A: 단일 아이 — 화살표 비활성화

- **검증 대상**: AC-007-02
- **사전 조건**: 아이가 1명인 사용자
- **테스트 단계**:
  1. 홈 화면을 연다
  2. 헤더의 좌우 화살표가 비활성화 상태(흐림 또는 숨김)로 표시되는지 확인한다
  3. 화살표를 탭해도 아무 동작이 일어나지 않는지 확인한다
- **기대 결과**: 화살표는 비활성화되어 있고 탭 시 동작하지 않는다

### TC-007-02-B: 다자녀 — 아이 전환 시 화면 갱신

- **검증 대상**: AC-007-02
- **사전 조건**: Case B 등 아이가 2명 이상인 사용자
- **테스트 단계**:
  1. 홈 화면을 연다 (아이 A 활성)
  2. 우측 화살표를 탭한다
  3. 헤더 이름이 아이 B로 바뀌는지 확인한다
  4. 헤더 프로필/주차 정보가 아이 B 기준으로 즉시 갱신되는지 확인한다
  5. 오늘의 질문 카드의 프로필·질문 텍스트가 아이 B 기준으로 갱신되는지 확인한다
  6. 책 진행도(n/50)의 n 값이 아이 B의 누적 답변 수로 갱신되는지 확인한다
  7. 타인 기록 피드는 변경되지 않는지 확인한다
- **기대 결과**: 아이 전환 시 헤더·질문 카드·책 진행도가 즉시 갱신되며, 타인 기록 피드는 영향받지 않는다

### TC-007-03: 알림 아이콘 red dot

- **검증 대상**: AC-007-03
- **사전 조건**: 사용자 계정에 알림이 도착한 상태
- **테스트 단계**:
  1. 안 읽은 알림이 0개인 상태에서 홈 진입 → red dot 미표시 확인
  2. 푸시 알림을 수신한 뒤 홈 진입 → red dot 표시 확인
  3. 알림 아이콘을 탭 → 알림 목록 화면으로 이동 확인
  4. 알림 목록에서 모두 읽음 처리 후 홈으로 복귀 → red dot 사라짐 확인
- **기대 결과**: 안 읽은 알림 유무에 따라 red dot이 정확히 표시/숨김된다

### TC-007-04: 오늘의 질문 카드 표시

- **검증 대상**: AC-007-04
- **사전 조건**: 사용자가 온보딩을 완료하고 활성 아이가 1명 이상인 상태
- **테스트 단계**:
  1. 홈 화면으로 진입한다
  2. 카드 좌측에 활성 아이의 프로필 이미지가 원형으로 표시되는지 확인한다
  3. 프로필 아래에 이름/태명과 주차/개월수가 표시되는지 확인한다
  4. 우측에 말풍선이 표시되는지 확인한다
  5. 말풍선의 텍스트가 아이 1인칭 시점 문장인지 확인한다 (예: "엄마, 오늘은…")
  6. 사용자 모드(임산부/양육자)와 주차에 맞는 질문 풀에서 선택되었는지 확인한다 (PRD-002 매칭 규칙 참조)
- **기대 결과**: 오늘의 질문 카드가 프로필·컨텍스트·1인칭 말풍선 구조로 표시된다

### TC-007-05: 다른 질문 보기 (회전 3개)

- **검증 대상**: AC-007-05
- **사전 조건**: 오늘의 질문 카드가 표시된 상태, 당일 처음 진입
- **테스트 단계**:
  1. 말풍선 우측 하단의 인덱스가 `1/3`으로 표시되는지 확인한다
  2. 우측 화살표를 1번 탭 → 인덱스 `2/3`, 질문 텍스트 변경 확인
  3. 우측 화살표를 한 번 더 탭 → 인덱스 `3/3`, 또 다른 질문 표시 확인
  4. 우측 화살표를 한 번 더 탭 → 동작하지 않거나 비활성화 상태 확인
  5. 좌측 화살표를 탭 → `2/3`로 이동 확인
  6. 자정을 넘긴 뒤 다시 진입 → 인덱스가 다시 `1/3`로 초기화되고 질문이 새로 갱신되는지 확인
- **기대 결과**: 하루 최대 3개의 질문을 회전 가능하며 자정에 초기화된다

### TC-007-06-A: 음성 기록 진입

- **검증 대상**: AC-007-06
- **사전 조건**: 오늘의 질문 카드가 표시된 상태
- **테스트 단계**:
  1. "목소리로 남기기" 버튼을 탭한다
  2. 하단에서 음성 녹음 모달이 슬라이드 업으로 열리는지 확인한다
  3. 모달에 녹음 시작 버튼이 있는지 확인한다
  4. 녹음을 완료하고 저장한다
  5. 저장된 기록에 현재 화면에 표시되었던 질문이 함께 저장되었는지 일기 탭에서 확인한다
- **기대 결과**: 음성 녹음 모달이 열리며 저장 시 표시된 질문과 답변이 함께 저장된다

### TC-007-06-B: 텍스트 기록 진입

- **검증 대상**: AC-007-06
- **사전 조건**: 오늘의 질문 카드가 표시된 상태
- **테스트 단계**:
  1. "글로 남기기" 버튼을 탭한다
  2. 하단에서 텍스트 입력 모달이 슬라이드 업으로 열리는지 확인한다
  3. 모달에 빈 입력 영역이 노출되는지 확인한다
  4. 텍스트를 입력하고 저장한다
  5. 저장된 기록에 현재 화면에 표시되었던 질문이 함께 저장되었는지 확인한다
- **기대 결과**: 텍스트 입력 모달이 열리며 저장 시 표시된 질문과 답변이 함께 저장된다

### TC-007-06-C: 회전된 질문 기준 저장

- **검증 대상**: AC-007-06, AC-007-05
- **사전 조건**: 오늘의 질문 카드가 표시된 상태
- **테스트 단계**:
  1. 우측 화살표를 2번 탭하여 `3/3` 질문을 표시한다
  2. "글로 남기기"를 탭하고 답변을 저장한다
  3. 일기 탭에서 저장된 기록을 확인한다
- **기대 결과**: 저장된 기록의 질문이 `3/3` 위치에 표시되었던 질문과 일치한다

### TC-007-07-A: 책 진행도 표시 (n < 50)

- **검증 대상**: AC-007-07
- **사전 조건**: 활성 아이 기준 누적 답변 수가 50 미만인 상태
- **테스트 단계**:
  1. 홈 화면을 연다
  2. 카드 하단에 `아이에게 전해줄 책이 만들어지고 있어요 (?) (n/50)` 형식의 텍스트가 표시되는지 확인한다
  3. `(?)` 아이콘을 탭한다
  4. 자서전 생성 안내 모달이 열리는지 확인한다
  5. 답변을 1개 추가 작성한다
  6. 홈으로 복귀했을 때 n 값이 1 증가했는지 확인한다
- **기대 결과**: 진행도가 정확히 표시되고 답변 작성 시 n이 실시간으로 증가한다

### TC-007-07-B: 50 도달 시 CTA 전환

- **검증 대상**: AC-007-07
- **사전 조건**: 활성 아이 기준 누적 답변 수가 49개인 상태
- **테스트 단계**:
  1. 답변 1개를 추가 작성하여 50개를 달성한다
  2. 홈으로 복귀한다
  3. 진행도 텍스트가 사라지고 "책 만들기" CTA 버튼이 표시되는지 확인한다
  4. CTA를 탭한다 → 자서전 탭으로 이동하는지 확인한다
- **기대 결과**: 50 도달 시 CTA로 자동 전환되며, 탭 시 자서전 탭으로 이동한다

### TC-007-07-C: 다자녀 — 아이별 독립 카운트

- **검증 대상**: AC-007-07, AC-007-02
- **사전 조건**: 아이 A(누적 30개), 아이 B(누적 10개)인 다자녀 사용자
- **테스트 단계**:
  1. 아이 A 활성 상태로 홈 진입 → `30/50` 표시 확인
  2. 헤더 화살표로 아이 B로 전환 → `10/50` 표시 확인
- **기대 결과**: 진행도 n 값이 활성 아이별로 독립적으로 카운트된다

### TC-007-10: 하단 네비게이션 탭 이동

- **검증 대상**: AC-007-10
- **사전 조건**: 홈 화면에 진입한 상태
- **테스트 단계**:
  1. 하단에 5개 탭(자서전·커뮤니티·홈·일기·설정)이 좌→우 순서대로 표시되는지 확인한다
  2. 홈 탭이 현재 선택 상태로 강조 표시되는지 확인한다
  3. 각 탭을 순서대로 탭하여 해당 화면으로 이동하는지 확인한다
  4. 다른 탭에서도 하단 네비게이션 바가 동일하게 노출되는지 확인한다
  5. 홈 탭이 중앙(3번째 위치)에 있는지 확인한다
- **기대 결과**: 5개 탭이 정의된 순서와 위치로 노출되며, 모든 탭에서 동일하게 표시되고 정상적으로 화면 이동이 일어난다
