# TEST-005: 기록 미디어 통합 테스트

## 대상 PRD

PRD-005: 기록 미디어 통합

## 테스트 케이스

### TC-005-01: 사진 촬영 첨부 테스트

- **검증 대상**: AC-005-01
- **사전 조건**: 사용자가 기록 작성 화면에 있다
- **테스트 단계**:
  1. 기록 작성 화면 하단에서 카메라 버튼을 확인한다
  2. 카메라 버튼을 탭하여 카메라를 실행한다
  3. 사진을 촬영한다
  4. 촬영한 사진이 기록에 썸네일로 표시되는지 확인한다
- **기대 결과**: 카메라로 촬영한 사진이 기록에 썸네일로 첨부되어 표시된다

### TC-005-02: 갤러리 사진 첨부 테스트

- **검증 대상**: AC-005-02
- **사전 조건**: 사용자가 기록 작성 화면에 있다
- **테스트 단계**:
  1. 기록 작성 화면 하단에서 갤러리 버튼을 탭한다
  2. 갤러리에서 여러 장의 사진을 선택한다
  3. 선택 완료 후 기록 화면으로 돌아온다
  4. 선택한 사진들이 썸네일 목록으로 표시되는지 확인한다
- **기대 결과**: 갤러리에서 선택한 여러 장의 사진이 기록에 썸네일 목록으로 표시된다

### TC-005-03: 영상 촬영 첨부 테스트

- **검증 대상**: AC-005-03
- **사전 조건**: 사용자가 기록 작성 화면에 있다
- **테스트 단계**:
  1. 기록 작성 화면 하단에서 영상 촬영 버튼을 탭한다
  2. 영상을 촬영하고 종료한다
  3. 촬영한 영상이 썸네일과 재생 시간과 함께 표시되는지 확인한다
- **기대 결과**: 촬영한 영상이 재생 시간이 표시된 썸네일로 기록에 첨부된다

### TC-005-04: 갤러리 영상 첨부 테스트

- **검증 대상**: AC-005-04
- **사전 조건**: 사용자가 기록 작성 화면에 있다
- **테스트 단계**:
  1. 갤러리에서 영상을 선택한다
  2. 선택한 영상이 기록에 표시되는지 확인한다
  3. 영상 썸네일에 재생 시간이 표시되는지 확인한다
- **기대 결과**: 갤러리에서 선택한 영상이 재생 시간이 표시된 썸네일로 기록에 첨부된다

### TC-005-05: 음성 메모 첨부 테스트

- **검증 대상**: AC-005-05
- **사전 조건**: 음성 녹음 후 텍스트 변환이 완료된 상태
- **테스트 단계**:
  1. 텍스트 변환 완료 후 '음성 원본도 저장' 옵션이 표시되는지 확인한다
  2. 옵션을 선택한다
  3. 음성 메모가 기록에 첨부되는지 확인한다
  4. 첨부된 음성 메모를 탭하여 재생되는지 확인한다
- **기대 결과**: 음성 원본이 재생 가능한 음성 메모로 기록에 첨부되며, 탭하면 재생된다

### TC-005-06: 미디어 미리보기 및 관리 테스트

- **검증 대상**: AC-005-06
- **사전 조건**: 기록에 미디어가 첨부된 상태
- **테스트 단계**:
  1. 첨부된 미디어 썸네일을 탭하여 전체 화면으로 표시되는지 확인한다
  2. 미디어에 캡션을 입력한다
  3. 미디어를 삭제한다
  4. 삭제 후 미디어가 목록에서 제거되었는지 확인한다
- **기대 결과**: 미디어를 전체 화면으로 볼 수 있고, 캡션 입력과 삭제가 정상 동작한다

### TC-005-07: 미디어 포함 기록 목록 표시 테스트

- **검증 대상**: AC-005-07
- **사전 조건**: 사진, 영상, 음성이 각각 첨부된 기록이 존재한다
- **테스트 단계**:
  1. '기록' 탭에서 기록 목록을 확인한다
  2. 미디어가 포함된 기록에 미디어 유형 아이콘이 표시되는지 확인한다
  3. 대표 썸네일이 기록 미리보기에 표시되는지 확인한다
- **기대 결과**: 기록 목록에서 미디어 유형 아이콘과 대표 썸네일이 표시된다

### TC-005-08: 미디어 AI 서사 연동 테스트

- **검증 대상**: AC-005-08
- **사전 조건**: 미디어가 첨부된 기록이 축적된 상태
- **테스트 단계**:
  1. AI 서사 생성을 요청한다
  2. 생성된 서사에 기록의 미디어가 포함되어 있는지 확인한다
  3. 서사 미리보기에서 미디어가 텍스트와 함께 표시되는지 확인한다
  4. 서사 편집에서 미디어를 제외하거나 순서를 변경할 수 있는지 확인한다
- **기대 결과**: 기록에 첨부된 미디어가 서사에 자동 포함되며, 편집 시 관리할 수 있다
