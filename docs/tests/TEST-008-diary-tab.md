# TEST-008: 일기 탭 — 내 기록 조회 및 관리 테스트

## 대상 PRD

[PRD-008: 일기 탭 — 내 기록 조회 및 관리](../prd/PRD-008-diary-tab.md)

본 테스트는 PRD-008의 AC-008-01 ~ AC-008-10을 모두 커버한다. 핵심 검증 포인트는 **일기 탭이 다른 탭과 달리 활성 아이 컨텍스트의 영향을 받지 않고 모든 아이 기록을 통합 표시**하는지, 그리고 각 카드가 어느 아이 기록인지 사용자가 즉시 식별 가능한지다.

## 테스트 케이스

### TC-008-01-A: 단일 아이 — 모든 기록 통합 표시

- **검증 대상**: AC-008-01, AC-008-10
- **사전 조건**: 활성 아이가 1명이고, 해당 아이로 작성된 기록이 3건 이상 있는 사용자
- **테스트 단계**:
  1. 하단 네비게이션에서 일기 탭을 탭한다
  2. 헤더 중앙에 `일기` 타이틀이 표시되는지 확인한다
  3. 헤더 좌측에 좌우 화살표나 아이 이름이 노출되지 않는지 확인한다
  4. 헤더 우측에 🔔 알림 아이콘이 노출되는지 확인한다
  5. 목록에 해당 아이의 기록 3건이 모두 시간 순으로 표시되는지 확인한다
- **기대 결과**: 일기 탭 헤더는 "일기" + 🔔만 표시하며, 단일 아이의 기록이 통합 목록 형태로 표시된다

### TC-008-01-B: 다자녀 — 모든 아이의 기록을 한 목록에 통합

- **검증 대상**: AC-008-01
- **사전 조건**: 아이가 2명 이상이며, 각 아이마다 서로 다른 기록 세트(예: 콩이 임신 기록 3건, 하준 양육 기록 4건)가 있는 사용자
- **테스트 단계**:
  1. 일기 탭에 진입한다
  2. 목록에 콩이 기록과 하준 기록이 **모두 한 화면에 섞여서** 시간 순으로 표시되는지 확인한다
  3. 각 카드 우상단에 그 기록 대상 아이의 컨텍스트 칩(예: `🌱 콩이 · 임신 28주차` 또는 `👶 하준 · 생후 5개월`)이 표시되는지 확인한다
- **기대 결과**: 두 아이의 기록이 단일 시간 축에 통합되어 표시되고, 카드 칩으로 각 기록의 대상 아이를 즉시 식별할 수 있다

### TC-008-01-C: 활성 아이 변경이 일기 탭에 영향 없음

- **검증 대상**: AC-008-01, AC-006-09 (갱신 후)
- **사전 조건**: 다자녀 사용자, 콩이와 하준 두 아이 모두 기록 존재
- **테스트 단계**:
  1. 홈 탭에서 활성 아이를 콩이로 설정한다
  2. 일기 탭에 진입한다 — 두 아이 기록이 모두 표시되는지 확인
  3. 목록을 임의 위치로 스크롤한다
  4. 홈 탭으로 돌아가 활성 아이를 하준으로 전환한다
  5. 다시 일기 탭에 진입한다
  6. 목록 내용과 스크롤 위치가 그대로 유지되는지 확인한다 (필터는 초기화될 수 있음)
  7. 콩이·하준 기록이 여전히 모두 섞여 표시되는지 확인한다
- **기대 결과**: 활성 아이 변경은 일기 탭 목록에 영향 없음. 일기 탭은 모든 아이의 통합 목록을 일관되게 보여준다

### TC-008-02-A: 월 단위 시간 그룹 헤더

- **검증 대상**: AC-008-02
- **사전 조건**: 2025년 9월~11월에 걸쳐 다수의 기록이 있는 사용자
- **테스트 단계**:
  1. 일기 탭에 진입한다
  2. 최상단 그룹 헤더가 `📅 2025년 11월` 형식인지 확인한다
  3. 아래로 스크롤하여 `📅 2025년 10월`, `📅 2025년 9월` 그룹 헤더가 차례로 나타나는지 확인한다
  4. 동일 월에 작성된 기록들이 같은 그룹 헤더 아래에 묶여 있는지 확인한다 (어느 아이 기록이든 동일 월이면 같은 그룹)
  5. 그룹 헤더가 스크롤 중 sticky하게 상단에 고정되는지 확인한다
- **기대 결과**: 월 단위 그룹 헤더가 정확한 형식으로 표시되고 sticky 동작이 정상 작동한다. 아이가 다른 기록도 같은 월이면 같은 그룹에 들어간다

### TC-008-02-B: 아이별 컨텍스트는 그룹 키가 아님

- **검증 대상**: AC-008-02, AC-008-03
- **사전 조건**: 같은 달에 콩이(임신 28주)와 하준(생후 5개월) 기록이 모두 작성된 다자녀 사용자
- **테스트 단계**:
  1. 일기 탭에 진입한다
  2. 해당 월 그룹 헤더 아래에 두 아이의 기록이 함께 나열되는지 확인한다
  3. 그룹 헤더에 임신 주차나 개월수 정보가 포함되지 않는지 확인한다 (그룹 헤더는 `📅 YYYY년 MM월` 만)
  4. 각 카드의 우상단 칩에 그 카드 대상 아이의 컨텍스트가 표시되는지 확인한다
- **기대 결과**: 임신주차·개월수는 그룹 키가 아닌 카드 내부 칩으로만 노출된다

### TC-008-03-A: 기록 카드 — 아이 컨텍스트 칩 표시

- **검증 대상**: AC-008-03
- **사전 조건**: 임신 28주차에 작성한 콩이 기록, 양육 5개월에 작성한 하준 기록 모두 보유
- **테스트 단계**:
  1. 일기 탭에서 두 카드를 확인한다
  2. 콩이 카드 우상단 1행에 `🌱 콩이 · 임신 28주차` 형식의 칩이 있는지 확인한다
  3. 하준 카드 우상단 1행에 `👶 하준 · 생후 5개월` 형식의 칩이 있는지 확인한다
  4. 두 카드 우상단 2행에 공개 여부 배지(🔒/🌐)가 있는지 확인한다
- **기대 결과**: 각 카드에 작성 시점 기준 아이 컨텍스트 칩이 모드별 이모지(`🌱`/`👶`/`🧒`)와 함께 표시된다

### TC-008-03-B: 단일 아이 사용자도 아이 컨텍스트 칩 표시

- **검증 대상**: AC-008-03
- **사전 조건**: 활성 아이가 1명(콩이)인 사용자, 기록 다수
- **테스트 단계**:
  1. 일기 탭에 진입하여 임의 카드를 확인한다
  2. 단일 아이 사용자라도 카드에 아이 컨텍스트 칩이 표시되는지 확인한다
- **기대 결과**: 단일 아이 사용자도 일관되게 아이 컨텍스트 칩이 표시된다 (다자녀 확장 시 일관성 유지)

### TC-008-03-C: 카드 표시 요소와 미디어 행

- **검증 대상**: AC-008-03
- **사전 조건**: 사진 2장·음성 메모 1개가 첨부된 비공개 기록과 첨부 없는 공개 기록을 가진 사용자
- **테스트 단계**:
  1. 일기 탭에서 두 카드를 확인한다
  2. 첫 카드에서 다음 요소가 모두 표시되는지 확인:
     - 좌상단 작성 날짜 `MM/DD (요일)` 형식
     - 우상단 1행 아이 컨텍스트 칩
     - 우상단 2행 `🔒 비공개` 배지
     - 본문 상단 `Q.` + 질문 1줄
     - 본문 하단 `A.` + 답변 미리보기 약 60자 + `...`
     - 하단 미디어 행에 `🖼️ ×2` + `🎙️`
  3. 두 번째 카드에서 첨부가 없으므로 미디어 행 자체가 표시되지 않는지 확인한다
  4. 두 번째 카드의 배지가 `🌐 공개`인지 확인한다
- **기대 결과**: 첨부 유무에 따라 미디어 행이 조건부로 노출되고, 공개 배지와 아이 컨텍스트 칩이 정확히 반영된다

### TC-008-04-A: 기록 상세 진입과 본문 표시

- **검증 대상**: AC-008-04
- **사전 조건**: 콩이의 임신 28주차에 작성된 사진 첨부·공개 기록 보유
- **테스트 단계**:
  1. 일기 탭에서 해당 기록 카드를 탭한다
  2. 상세 화면이 push 전환으로 열리는지 확인한다
  3. 상단 메타에 `2025년 11월 22일 (금)` 작성일, `🌱 콩이 · 임신 28주차` 아이 컨텍스트 칩, `🌐 공개` 배지가 표시되는지 확인한다
  4. 본문에 인용 스타일의 질문, 그 아래 전체 답변(말줄임 없음, 줄바꿈 보존), 그 아래 사진이 순서대로 표시되는지 확인한다
  5. 우상단에 `⋯` 더보기 버튼이 노출되는지 확인한다
  6. back 버튼으로 일기 탭 목록으로 복귀 시 이전 스크롤 위치가 유지되는지 확인한다
- **기대 결과**: 상세 화면이 정의된 구성대로 표시되며, 복귀 시 스크롤 위치가 보존된다

### TC-008-04-B: 음성 원본이 있는 기록 상세

- **검증 대상**: AC-008-04
- **사전 조건**: 음성으로 작성하고 음성 원본을 저장한 기록
- **테스트 단계**:
  1. 해당 기록의 상세 화면에 진입한다
  2. 답변 본문 위에 `음성 원본 있음 · 재생` 링크가 노출되는지 확인한다
  3. 첨부 미디어 섹션에 음성 메모 재생 컨트롤(재생 버튼·진행 바·총 길이)이 표시되는지 확인한다
- **기대 결과**: 음성 원본 진입점과 음성 메모 재생 컨트롤이 모두 노출된다

### TC-008-05-A: 사후 편집 — 본문 텍스트 수정

- **검증 대상**: AC-008-05
- **사전 조건**: 텍스트만으로 작성된 기록 상세 화면에 진입한 상태
- **테스트 단계**:
  1. `⋯` → `편집`을 탭한다
  2. 편집 화면에서 답변 본문 텍스트를 수정한다
  3. 작성 일자 / 질문 텍스트 / 아이 컨텍스트가 비편집(read-only) 상태인지 확인한다
  4. 저장을 탭하면 상세 화면으로 복귀하고 변경된 본문이 반영되는지 확인한다
- **기대 결과**: 본문은 수정 가능하지만 작성 일자·질문·아이 컨텍스트는 변경 불가하며, 저장 시 즉시 반영된다

### TC-008-05-B: 다른 아이로 옮기기 불가

- **검증 대상**: AC-008-05
- **사전 조건**: 다자녀 사용자, 콩이 기록 상세 화면에서 편집 진입
- **테스트 단계**:
  1. 편집 화면에서 대상 아이를 다른 아이(하준)로 변경하려는 UI가 노출되지 않는지 확인한다
  2. 아이 컨텍스트 칩이 read-only로 표시되는지 확인한다
- **기대 결과**: 작성 시점의 의도 보존을 위해 다른 아이로 옮기는 기능은 없다

### TC-008-05-C: 편집 취소 시 변경 폐기 경고

- **검증 대상**: AC-008-05
- **사전 조건**: 편집 화면에서 본문에 변경 사항을 가한 상태
- **테스트 단계**:
  1. back 버튼이나 취소 버튼을 탭한다
  2. `수정 사항이 저장되지 않았습니다` 확인 모달이 표시되는지 확인한다
  3. 확인을 탭하면 변경 사항이 폐기되고 상세 화면으로 복귀하는지 확인한다
- **기대 결과**: 변경이 있을 때만 확인 모달이 노출되고, 확인 시 변경이 폐기된다

### TC-008-06-A: 삭제 확인 모달 — 아이 이름 치환

- **검증 대상**: AC-008-06
- **사전 조건**: 콩이 기록(콩이의 책 진행도 12/50) 상세 화면에 진입
- **테스트 단계**:
  1. `⋯` → `삭제`를 탭한다
  2. 확인 모달의 본문에 `콩이의 책에도 포함되지 않게 됩니다`가 정확히 치환되어 표시되는지 확인한다
  3. `삭제` 버튼이 코랄(위험 강조) 색상인지 확인한다
  4. `삭제`를 탭하면 일기 탭 목록으로 복귀하고 해당 카드가 즉시 사라지는지 확인한다
  5. 토스트 `기록이 삭제되었습니다`가 약 2초간 표시되는지 확인한다
- **기대 결과**: 본문의 아이 이름이 대상 아이로 정확히 치환되고, 삭제가 적용되며 토스트가 표시된다

### TC-008-06-B: 삭제는 해당 아이의 책 진행도만 차감

- **검증 대상**: AC-008-06
- **사전 조건**: 다자녀 사용자, 콩이 책 진행도 12/50, 하준 책 진행도 8/50
- **테스트 단계**:
  1. 콩이 기록 1건을 삭제한다
  2. 홈 탭에서 활성 아이를 콩이로 두고 책 진행도가 11/50으로 차감되었는지 확인한다
  3. 활성 아이를 하준으로 전환하고 책 진행도가 8/50 그대로인지 확인한다
- **기대 결과**: 삭제 대상 아이의 책 진행도만 차감되고, 다른 아이의 진행도는 영향 받지 않는다

### TC-008-06-C: 공개 기록 삭제 시 커뮤니티 피드 즉시 제거

- **검증 대상**: AC-008-06
- **사전 조건**: 공개로 설정되어 커뮤니티 피드에 노출 중인 기록
- **테스트 단계**:
  1. 다른 계정/세션에서 해당 기록이 커뮤니티 피드(또는 홈의 타인 기록 피드)에 노출되는지 확인한다
  2. 작성자 계정에서 해당 기록을 삭제한다
  3. 다른 세션을 새로고침하여 해당 기록이 더 이상 노출되지 않는지 확인한다
- **기대 결과**: 공개 기록 삭제가 커뮤니티 노출에서 즉시 제거된다

### TC-008-07-A: 비공개 → 공개 전환 (상세 화면 액션)

- **검증 대상**: AC-008-07
- **사전 조건**: 비공개로 설정된 기록 상세 화면에 진입
- **테스트 단계**:
  1. `⋯` 더보기를 탭한다
  2. 액션 시트의 라벨이 `공개로 전환`인지 확인한다
  3. 탭 시 토스트 `이 기록이 다른 사용자에게 공개됩니다`가 표시되는지 확인한다
  4. 상세 화면 상단 배지가 `🔒 비공개` → `🌐 공개`로 갱신되는지 확인한다
  5. 일기 탭 목록으로 복귀하여 카드 배지도 갱신되었는지 확인한다
  6. 커뮤니티 탭(또는 홈 피드)에 해당 기록이 노출 대상으로 포함되는지 확인한다
- **기대 결과**: 즉시 공개 상태로 전환되며 커뮤니티 노출 대상에 포함된다

### TC-008-07-B: 공개 → 비공개 전환 시 공감 수 유지

- **검증 대상**: AC-008-07
- **사전 조건**: 공감 수 50이 누적된 공개 기록
- **테스트 단계**:
  1. 기록을 비공개로 전환한다
  2. 커뮤니티 피드에서 사라지는지 확인한다
  3. 다시 공개로 전환한다
  4. 공감 수가 50으로 복원되어 노출되는지 확인한다
- **기대 결과**: 비공개 전환 후 재공개 시 공감 수가 데이터로 보존되어 그대로 복원된다

### TC-008-08-A: 아이 필터 — 다자녀 다중 선택

- **검증 대상**: AC-008-08
- **사전 조건**: 3명의 아이(콩이·하준·서연) 기록을 가진 사용자
- **테스트 단계**:
  1. 일기 탭에서 `⚙️` 필터 아이콘을 탭한다
  2. 필터 시트가 하단에서 슬라이드 업되며, 최상단에 아이 필터 칩 3개(`🌱 콩이`/`👶 하준`/`🧒 서연`)가 표시되는지 확인한다
  3. `콩이`와 `서연`만 선택하고 `적용`을 탭한다
  4. 목록에 콩이 또는 서연 기록만 표시되고 하준 기록은 보이지 않는지 확인한다
  5. `⚙️` 아이콘 우상단에 필터 배지(`⚙️¹`)가 표시되는지 확인한다
- **기대 결과**: 아이 필터가 다중 선택으로 작동하고, 다른 아이 기록은 즉시 숨겨진다

### TC-008-08-B: 단일 아이 사용자는 아이 필터 미노출

- **검증 대상**: AC-008-08
- **사전 조건**: 활성 아이가 1명인 사용자
- **테스트 단계**:
  1. 일기 탭에서 `⚙️` 필터 시트를 연다
  2. 시트에 아이 필터 섹션 자체가 표시되지 않는지 확인한다
  3. 기간·미디어·공개 여부 필터만 노출되는지 확인한다
- **기대 결과**: 단일 아이 사용자에게는 무의미한 아이 필터가 노출되지 않는다

### TC-008-08-C: 미디어·기간 필터 조합

- **검증 대상**: AC-008-08
- **사전 조건**: 사진 첨부 기록 3건, 음성 메모 첨부 기록 2건, 첨부 없는 기록 4건이 있는 사용자
- **테스트 단계**:
  1. 필터 시트에서 `사진 포함`과 `음성 메모 포함`을 미디어 칩에서 다중 선택한다
  2. 기간 필터를 `최근 1개월`로 설정한다
  3. `적용`을 탭한다
  4. 최근 1개월 내에 작성되었고 사진 또는 음성 메모를 포함한 기록만 표시되는지 확인한다
  5. `⚙️` 아이콘 우상단에 필터 배지(`⚙️²`)가 표시되는지 확인한다
- **기대 결과**: 여러 필터 조건이 AND로 결합되어 정확히 좁혀진다

### TC-008-08-D: 필터 초기화 정책

- **검증 대상**: AC-008-08
- **사전 조건**: 일기 탭에서 필터를 적용한 상태
- **테스트 단계**:
  1. 하단 네비로 홈 탭 → 다시 일기 탭으로 진입한다
  2. 필터가 초기화되어 있는지 확인한다 (배지 없음, 전체 목록 표시)
- **기대 결과**: 탭 이탈 후 재진입 시 필터는 초기화된다

### TC-008-09-A: 기록 0건 빈 상태

- **검증 대상**: AC-008-09
- **사전 조건**: 어느 아이에게도 기록을 작성하지 않은 신규 사용자
- **테스트 단계**:
  1. 일기 탭에 진입한다
  2. 화면 중앙에 `📓` 일러스트와 메인 카피 `아직 첫 기록이 없어요`, 보조 카피, `홈으로 가기` CTA가 표시되는지 확인한다
  3. 카피에 특정 아이 이름이 들어가지 않는지 확인한다 (예: "이 아이의" 등의 문구가 없음)
  4. `홈으로 가기` CTA를 탭하면 홈 탭으로 전환되는지 확인한다
  5. 헤더와 하단 네비게이션이 정상 노출되는지 확인한다
- **기대 결과**: 아이를 특정하지 않는 일반화된 카피와 CTA가 노출된다

### TC-008-09-B: 필터 결과 0건 빈 상태

- **검증 대상**: AC-008-09
- **사전 조건**: 기록은 다수 있지만 필터를 적용하면 0건이 되는 사용자
- **테스트 단계**:
  1. 필터에서 매칭되는 기록이 없는 조합을 적용한다
  2. 화면 중앙에 `🔍` 이모지와 메인 카피 `조건에 맞는 기록이 없어요`, 보조 카피, `필터 초기화` CTA가 표시되는지 확인한다
  3. `필터 초기화` CTA를 탭하면 필터가 초기화되고 전체 목록으로 복귀하는지 확인한다
- **기대 결과**: 0건 안내와 필터 초기화 CTA가 노출되며, 탭 시 정상 복원된다

### TC-008-10-A: 일기 탭 헤더 구성

- **검증 대상**: AC-008-10
- **사전 조건**: 다자녀 사용자 (헤더에 아이 전환 화살표가 있어야 할지 검증)
- **테스트 단계**:
  1. 일기 탭에 진입한다
  2. 헤더 좌측이 비어 있는지 확인한다 (◀ 화살표 없음)
  3. 헤더 중앙에 `일기` 타이틀이 표시되는지 확인한다
  4. 헤더 우측에 🔔 알림 아이콘만 표시되는지 확인한다
  5. 헤더 어디에도 아이 이름이 노출되지 않는지 확인한다
- **기대 결과**: 일기 탭 헤더는 홈 탭과 다르게 활성 아이 정보를 노출하지 않는다

### TC-008-10-B: 하단 네비게이션 — 일기 탭 선택 상태

- **검증 대상**: AC-008-10
- **사전 조건**: 일기 탭에 진입한 상태
- **테스트 단계**:
  1. 하단에 5개 탭(자서전·커뮤니티·홈·일기·설정)이 좌→우 순서로 표시되는지 확인한다
  2. 일기 탭이 현재 선택 상태로 강조 표시(코랄 컬러)되는지 확인한다
  3. 홈 탭으로 이동했다가 다시 일기 탭으로 복귀했을 때 스크롤 위치가 유지되는지 확인한다 (필터는 초기화됨 — TC-008-08-D)
- **기대 결과**: 5탭 구성과 선택 강조가 PRD-007 AC-007-10과 동일하며, 탭 복귀 시 스크롤은 유지되고 필터는 초기화된다
