# TEST-008: 일기 탭 — 내 기록 조회 및 관리 테스트

## 대상 PRD

[PRD-008: 일기 탭 — 내 기록 조회 및 관리](../prd/PRD-008-diary-tab.md)

본 테스트는 PRD-008의 AC-008-01 ~ AC-008-10을 모두 커버한다. 헤더·하단 네비게이션의 시각 명세 자체는 PRD-007에서 검증되므로 본 테스트는 "일기 탭 안에서 그것들이 PRD-008 동작과 어떻게 연동되는지"만 검증한다.

## 테스트 케이스

### TC-008-01-A: 활성 아이 기준 목록 표시 (단일 아이)

- **검증 대상**: AC-008-01
- **사전 조건**: 활성 아이가 1명이고, 해당 아이로 작성된 기록이 3건 이상 있는 사용자
- **테스트 단계**:
  1. 하단 네비게이션에서 일기 탭을 탭한다
  2. 헤더에 활성 아이의 이름/태명이 표시되는지 확인한다
  3. 좌우 화살표가 비활성 상태(흐림 또는 숨김)인지 확인한다
  4. 목록에 해당 아이의 기록이 시간 순으로 표시되는지 확인한다
- **기대 결과**: 활성 아이의 기록만 시간 순 정렬되어 표시되며, 좌우 화살표는 비활성 상태다

### TC-008-01-B: 활성 아이 전환 시 목록 즉시 갱신 (다자녀)

- **검증 대상**: AC-008-01
- **사전 조건**: 아이가 2명 이상이며, 각 아이마다 서로 다른 기록 세트가 있는 사용자
- **테스트 단계**:
  1. 일기 탭에 진입한다 — 현재 활성 아이(예: 하준)의 기록이 표시되는지 확인
  2. 목록을 임의 위치로 스크롤한다
  3. 헤더 좌측 화살표(◀)를 탭한다
  4. 다음/이전 아이(예: 서연)의 기록 목록으로 즉시 갱신되는지 확인한다
  5. 스크롤 위치가 최상단으로 리셋되는지 확인한다
  6. 헤더의 아이 이름과 컨텍스트도 함께 갱신되었는지 확인한다
- **기대 결과**: 아이 전환과 동시에 목록 전체가 새 아이 기준으로 갱신되고 스크롤이 최상단으로 리셋된다

### TC-008-02-A: 시간 그룹 헤더 — 임신 모드

- **검증 대상**: AC-008-02
- **사전 조건**: 임신 26주차부터 28주차까지에 걸쳐 작성된 기록 5건 이상이 있는 활성 아이
- **테스트 단계**:
  1. 일기 탭에 진입한다
  2. 최상단 그룹 헤더가 `임신 NN주차 · YYYY년 MM월` 형식인지 확인한다 (예: `임신 28주차 · 2025년 11월`)
  3. 아래로 스크롤하여 27주차·26주차 그룹 헤더가 차례로 나타나는지 확인한다
  4. 동일 주차에 작성된 기록들이 같은 그룹 헤더 아래에 묶여 있는지 확인한다
  5. 그룹 헤더가 스크롤 중 sticky하게 상단에 고정되는지 확인한다
- **기대 결과**: 임신 주차 단위 그룹 헤더가 정확한 형식으로 표시되고 sticky 동작이 정상 작동한다

### TC-008-02-B: 시간 그룹 헤더 — 양육 모드 개월/나이 분기

- **검증 대상**: AC-008-02
- **사전 조건**: 생후 11개월부터 13개월에 걸쳐 작성된 기록을 가진 양육 모드 활성 아이
- **테스트 단계**:
  1. 일기 탭에 진입한다
  2. 12개월 이하 기간에 작성된 기록의 그룹 헤더가 `생후 NN개월 · YYYY년 MM월` 형식인지 확인한다
  3. 13개월 이상 기간에 작성된 기록의 그룹 헤더가 `NN살 · YYYY년 MM월` 형식인지 확인한다
- **기대 결과**: 12개월 경계에서 개월수 표기와 나이 표기가 자동 분기되어 표시된다

### TC-008-02-C: 임신 → 양육 전환 기록 그룹 연속성

- **검증 대상**: AC-008-02
- **사전 조건**: 출산 전후로 임신 기록과 양육 기록이 모두 존재하는 Case A·B 활성 아이
- **테스트 단계**:
  1. 일기 탭에 진입하여 최상단(최신 기록)으로 스크롤한다
  2. 양육 기록 그룹과 임신 기록 그룹이 모두 표시되는지 확인한다
  3. 두 그룹 사이에 시각적 구분선이 표시되며, 양육 그룹이 위쪽(최신), 임신 그룹이 아래쪽(과거)에 위치하는지 확인한다
- **기대 결과**: 출산 전환을 가로지르는 기록도 모두 표시되며, 두 모드의 그룹이 자연스럽게 이어진다

### TC-008-03: 기록 카드 표시 요소

- **검증 대상**: AC-008-03
- **사전 조건**: 사진 2장·음성 메모 1개가 첨부된 비공개 기록과 첨부 없는 공개 기록을 가진 활성 아이
- **테스트 단계**:
  1. 일기 탭에 진입하여 두 기록 카드를 확인한다
  2. 첫 번째 카드에서 다음 요소가 모두 표시되는지 확인:
     - 좌상단 작성 날짜 `MM/DD (요일)` 형식
     - 우상단 `🔒 비공개` 배지
     - 본문 상단 `Q.` 접두어 + 질문 1줄
     - 본문 하단 `A.` 접두어 + 답변 미리보기 약 60자 + `...`
     - 하단 미디어 행에 `🖼️ ×2` + `🎙️`
  3. 두 번째 카드에서 첨부가 없으므로 미디어 행 자체가 표시되지 않는지 확인한다
  4. 두 번째 카드의 배지가 `🌐 공개`인지 확인한다
- **기대 결과**: 첨부 유무에 따라 미디어 행이 조건부로 노출되고, 공개 배지가 정확히 반영된다

### TC-008-04-A: 기록 상세 진입과 본문 표시

- **검증 대상**: AC-008-04
- **사전 조건**: 임신 28주차에 작성된 사진 첨부·공개 기록이 있는 활성 아이
- **테스트 단계**:
  1. 일기 탭에서 해당 기록 카드를 탭한다
  2. 상세 화면이 push 전환으로 열리는지 확인한다
  3. 상단 메타에 `YYYY년 MM월 DD일 (요일) · 임신 28주차 · 🌐 공개`가 표시되는지 확인한다
  4. 본문에 인용 스타일의 질문, 그 아래 전체 답변(말줄임 없음, 줄바꿈 보존), 그 아래 사진이 순서대로 표시되는지 확인한다
  5. 우상단에 `⋯` 더보기 버튼이 노출되는지 확인한다
  6. back 버튼으로 일기 탭 목록으로 복귀 시 이전 스크롤 위치가 유지되는지 확인한다
- **기대 결과**: 상세 화면이 정의된 구성대로 표시되며, 복귀 시 스크롤 위치가 보존된다

### TC-008-04-B: 음성 원본이 있는 기록 상세

- **검증 대상**: AC-008-04
- **사전 조건**: 음성으로 작성하고 음성 원본을 저장한 기록
- **테스트 단계**:
  1. 해당 기록의 상세 화면에 진입한다
  2. 답변 본문 위에 `음성 원본 있음 · 재생` 링크가 노출되는지 확인한다
  3. 첨부 미디어 섹션에 음성 메모 재생 컨트롤(재생 버튼·진행 바·총 길이)이 표시되는지 확인한다
- **기대 결과**: 음성 원본 진입점과 음성 메모 재생 컨트롤이 모두 노출된다

### TC-008-05-A: 사후 편집 — 본문 텍스트 수정

- **검증 대상**: AC-008-05
- **사전 조건**: 텍스트만으로 작성된 기록 상세 화면에 진입한 상태
- **테스트 단계**:
  1. `⋯` → `편집`을 탭한다
  2. 편집 화면에서 답변 본문 텍스트를 수정한다
  3. 작성 일자 필드가 비편집(read-only) 상태인지 확인한다
  4. 질문 텍스트가 비편집 상태인지 확인한다
  5. 저장을 탭하면 상세 화면으로 복귀하고 변경된 본문이 반영되는지 확인한다
- **기대 결과**: 본문은 수정 가능하지만 작성 일자·질문은 변경 불가하며, 저장 시 즉시 반영된다

### TC-008-05-B: 편집 취소 시 변경 폐기 경고

- **검증 대상**: AC-008-05
- **사전 조건**: 편집 화면에서 본문에 변경 사항을 가한 상태
- **테스트 단계**:
  1. back 버튼이나 취소 버튼을 탭한다
  2. `수정 사항이 저장되지 않았습니다` 확인 모달이 표시되는지 확인한다
  3. 확인을 탭하면 변경 사항이 폐기되고 상세 화면으로 복귀하는지 확인한다
- **기대 결과**: 변경이 있을 때만 확인 모달이 노출되고, 확인 시 변경이 폐기된다

### TC-008-06-A: 삭제 확인 모달과 영구 삭제

- **검증 대상**: AC-008-06
- **사전 조건**: 활성 아이의 책 진행도가 12/50인 상태에서 임의 기록 상세 화면에 진입
- **테스트 단계**:
  1. `⋯` → `삭제`를 탭한다
  2. 확인 모달의 제목·본문·버튼 라벨이 PRD-008 AC-008-06 명세대로인지 확인한다
  3. `삭제` 버튼이 코랄(위험 강조) 색상인지 확인한다
  4. `삭제`를 탭하면 일기 탭 목록으로 복귀하고 해당 카드가 즉시 사라지는지 확인한다
  5. 토스트 `기록이 삭제되었습니다`가 약 2초간 표시되는지 확인한다
  6. 홈 탭으로 이동하여 책 진행도가 11/50으로 차감되었는지 확인한다
- **기대 결과**: 삭제가 영구 적용되고 책 진행도에서 차감되며, 토스트가 표시된다

### TC-008-06-B: 공개 기록 삭제 시 커뮤니티 피드 즉시 제거

- **검증 대상**: AC-008-06
- **사전 조건**: 공개로 설정되어 커뮤니티 피드에 노출 중인 기록
- **테스트 단계**:
  1. 다른 계정/세션에서 해당 기록이 커뮤니티 피드(또는 홈의 타인 기록 피드)에 노출되는지 확인한다
  2. 작성자 계정에서 해당 기록을 삭제한다
  3. 다른 세션을 새로고침하여 해당 기록이 더 이상 노출되지 않는지 확인한다
- **기대 결과**: 공개 기록 삭제가 커뮤니티 노출에서 즉시 제거된다

### TC-008-07-A: 비공개 → 공개 전환 (상세 화면 액션)

- **검증 대상**: AC-008-07
- **사전 조건**: 비공개로 설정된 기록 상세 화면에 진입
- **테스트 단계**:
  1. `⋯` 더보기를 탭한다
  2. 액션 시트의 라벨이 `공개로 전환`인지 확인한다
  3. 탭 시 토스트 `이 기록이 다른 사용자에게 공개됩니다`가 표시되는지 확인한다
  4. 상세 화면 상단 배지가 `🔒 비공개` → `🌐 공개`로 갱신되는지 확인한다
  5. 일기 탭 목록으로 복귀하여 카드 배지도 갱신되었는지 확인한다
  6. 커뮤니티 탭(또는 홈 피드)에 해당 기록이 노출 대상으로 포함되는지 확인한다
- **기대 결과**: 즉시 공개 상태로 전환되며 커뮤니티 노출 대상에 포함된다

### TC-008-07-B: 공개 → 비공개 전환 시 공감 수 유지

- **검증 대상**: AC-008-07
- **사전 조건**: 공감 수 50이 누적된 공개 기록
- **테스트 단계**:
  1. 기록을 비공개로 전환한다
  2. 커뮤니티 피드에서 사라지는지 확인한다
  3. 다시 공개로 전환한다
  4. 공감 수가 50으로 복원되어 노출되는지 확인한다
- **기대 결과**: 비공개 전환 후 재공개 시 공감 수가 데이터로 보존되어 그대로 복원된다

### TC-008-08-A: 미디어 칩 다중 선택 필터

- **검증 대상**: AC-008-08
- **사전 조건**: 사진 첨부 기록 3건, 음성 메모 첨부 기록 2건, 첨부 없는 기록 4건이 있는 활성 아이
- **테스트 단계**:
  1. 일기 탭에서 `⚙️` 필터 아이콘을 탭한다
  2. 필터 시트가 하단에서 슬라이드 업되는지 확인한다
  3. 미디어 필터에서 `사진 포함`과 `음성 메모 포함`을 모두 선택한다
  4. `적용`을 탭한다
  5. 목록에 사진 또는 음성 메모를 가진 기록(5건)만 표시되는지 확인한다
  6. `⚙️` 아이콘 우상단에 적용 필터 수 배지(`⚙️²` 등)가 표시되는지 확인한다
- **기대 결과**: 선택된 미디어 종류를 가진 기록만 표시되고, 필터 배지가 노출된다

### TC-008-08-B: 사용자 지정 기간 필터

- **검증 대상**: AC-008-08
- **사전 조건**: 다양한 시점에 작성된 기록 다수
- **테스트 단계**:
  1. 필터 시트에서 `사용자 지정`을 선택한다
  2. 시작일과 종료일을 입력한다
  3. 적용 시 해당 기간에 작성된 기록만 표시되는지 확인한다
- **기대 결과**: 사용자 지정 기간 안의 기록만 정확히 필터링된다

### TC-008-08-C: 필터 유지·초기화 정책

- **검증 대상**: AC-008-08
- **사전 조건**: 다자녀 사용자, 일기 탭에서 미디어 필터를 적용한 상태
- **테스트 단계**:
  1. 헤더의 ▶ 화살표로 다른 아이로 전환한다
  2. 다른 아이의 일기 탭에서도 동일 필터가 적용되어 있는지 확인한다 (필터 배지 유지)
  3. 하단 네비로 홈 탭 → 다시 일기 탭으로 진입한다
  4. 필터가 초기화되어 있는지 확인한다 (배지 없음, 전체 목록 표시)
- **기대 결과**: 필터는 아이 전환 시 유지되고, 탭 이탈 후 재진입 시 초기화된다

### TC-008-09-A: 기록 0건 빈 상태

- **검증 대상**: AC-008-09
- **사전 조건**: 활성 아이 기준 기록이 0건인 사용자 (예: 새로 추가한 아이)
- **테스트 단계**:
  1. 일기 탭에 진입한다
  2. 화면 중앙에 `📓` 일러스트와 메인 카피 `아직 이 아이의 첫 기록이 없어요`, 보조 카피, `홈으로 가기` CTA가 표시되는지 확인한다
  3. `홈으로 가기` CTA를 탭하면 홈 탭으로 전환되는지 확인한다
  4. 헤더와 하단 네비게이션이 정상 노출되는지 확인한다
- **기대 결과**: 안내 화면과 CTA가 노출되며, 헤더·네비는 그대로 사용 가능하다

### TC-008-09-B: 필터 결과 0건 빈 상태

- **검증 대상**: AC-008-09
- **사전 조건**: 기록은 다수 있지만 필터를 적용하면 0건이 되는 활성 아이
- **테스트 단계**:
  1. 필터에서 매칭되는 기록이 없는 조합을 적용한다
  2. 화면 중앙에 `🔍` 이모지와 메인 카피 `조건에 맞는 기록이 없어요`, 보조 카피, `필터 초기화` CTA가 표시되는지 확인한다
  3. `필터 초기화` CTA를 탭하면 필터가 초기화되고 전체 목록으로 복귀하는지 확인한다
- **기대 결과**: 0건 안내와 필터 초기화 CTA가 노출되며, 탭 시 정상 복원된다

### TC-008-10: 하단 네비게이션 — 일기 탭 선택 상태

- **검증 대상**: AC-008-10
- **사전 조건**: 일기 탭에 진입한 상태
- **테스트 단계**:
  1. 하단에 5개 탭(자서전·커뮤니티·홈·일기·설정)이 좌→우 순서로 표시되는지 확인한다
  2. 일기 탭이 현재 선택 상태로 강조 표시(코랄 컬러)되는지 확인한다
  3. 홈 탭으로 이동했다가 다시 일기 탭으로 복귀했을 때 스크롤 위치가 유지되는지 확인한다 (AC-008-08의 필터는 초기화)
- **기대 결과**: 5탭 구성과 선택 강조가 PRD-007 AC-007-10과 동일하며, 탭 복귀 시 스크롤은 유지되고 필터는 초기화된다
