# TEST-002: 매일 다른 질문 알림 테스트

## 대상 PRD

PRD-002: 매일 다른 질문 알림

> **2026-08-08 개정**: 질문 모델이 아이 단계(임신 주차 또는 생후 나이)로 일반화됨에 따라, 임신 전용이던 TC 를 임산부(-A)·양육자(-B) 케이스로 분기하고 단계 스냅샷·폴백 TC 를 추가했다.

## AC ↔ TC 매핑

| AC | TC |
|---|---|
| AC-002-01 오늘의 질문 표시 | TC-002-01-A, TC-002-01-B |
| AC-002-02 아이 단계별 질문 매칭 | TC-002-02-A, TC-002-02-B, TC-002-02-C |
| AC-002-03 질문에서 기록으로 연결 | TC-002-03-A, TC-002-03-B, TC-002-03-C |
| AC-002-04 질문 알림 발송 | TC-002-04 |
| AC-002-05 단계 산출 불가 시 폴백 | TC-002-05-A, TC-002-05-B |

## 테스트 케이스

### TC-002-01-A: 오늘의 질문 표시 — 임산부

- **검증 대상**: AC-002-01
- **사전 조건**: 출산 예정일이 등록된 임신 중 아이가 활성 컨텍스트인 상태
- **테스트 단계**:
  1. 홈 화면으로 이동한다
  2. 오늘의 질문 카드가 표시되는지 확인한다
  3. 임신 주차 정보가 함께 표시되는지 확인한다 (표기 형식은 PRD-007 AC-007-01)
  4. 질문 안내 문구가 포함되어 있는지 확인한다
- **기대 결과**: 오늘의 질문 카드가 임신 주차와 함께 홈 화면에 표시된다

### TC-002-01-B: 오늘의 질문 표시 — 양육자

- **검증 대상**: AC-002-01
- **사전 조건**: 생년월일이 등록된 양육 중 아이가 활성 컨텍스트인 상태 (Case C 또는 출산 전환 완료)
- **테스트 단계**:
  1. 홈 화면으로 이동한다
  2. 오늘의 질문 카드가 표시되는지 확인한다
  3. **생후 나이 정보**가 함께 표시되는지 확인한다 (예: `5개월 (152일째)`)
  4. 임신 주차 표기가 노출되지 않는지 확인한다
- **기대 결과**: 오늘의 질문 카드가 생후 나이와 함께 표시되며, 임신 주차 표기는 나타나지 않는다

### TC-002-02-A: 단계별 질문 매칭 — 임신 축

- **검증 대상**: AC-002-02
- **사전 조건**: 출산 예정일이 등록된 상태
- **테스트 단계**:
  1. 현재 임신 주차를 확인한다
  2. 제공된 질문이 해당 주차에 적합한지 확인한다
  3. 다음 날 다시 접속하여 다른 질문이 제공되는지 확인한다
  4. 이전에 받은 질문이 반복되지 않는지 확인한다
- **기대 결과**: 임신 주차에 맞는 질문이 매일 중복 없이 제공된다

### TC-002-02-B: 단계별 질문 매칭 — 양육 축

- **검증 대상**: AC-002-02
- **사전 조건**: 생년월일이 등록된 양육 중 아이가 활성 상태
- **테스트 단계**:
  1. 현재 생후 나이를 확인한다
  2. 제공된 질문이 해당 시기에 적합한지 확인한다
  3. 다음 날 다시 접속하여 다른 질문이 제공되는지 확인한다
  4. 이전에 받은 질문이 반복되지 않는지 확인한다
- **기대 결과**: 생후 나이에 맞는 질문이 매일 중복 없이 제공된다

### TC-002-02-C: 두 풀의 분리 — 케이스 혼합 금지

- **검증 대상**: AC-002-02
- **사전 조건**: 임신 중 아이와 양육 중 아이를 모두 가진 다자녀 사용자 (Case B)
- **테스트 단계**:
  1. 임신 중 아이를 활성 컨텍스트로 두고 오늘의 질문을 확인한다
  2. 헤더의 아이 전환으로 양육 중 아이로 전환한다 (PRD-006 AC-006-08)
  3. 전환 후 오늘의 질문이 양육 단계 질문으로 갱신되는지 확인한다
  4. 각 질문이 반대 축의 문항(임신 아이에게 양육 질문, 양육 아이에게 임신 질문)을 포함하지 않는지 확인한다
  5. 아이별 질문 히스토리가 서로 독립적인지 확인한다
- **기대 결과**: 아이 전환에 따라 질문이 해당 아이의 단계 축 풀에서 선택되며, 두 풀은 섞이지 않는다

### TC-002-03-A: 질문에서 기록 연결

- **검증 대상**: AC-002-03
- **사전 조건**: 오늘의 질문이 표시된 상태
- **테스트 단계**:
  1. 질문 카드에서 음성 기록 또는 텍스트 기록 버튼을 확인한다
  2. 기록 버튼을 탭하여 기록을 작성한다
  3. 저장된 기록에 해당 질문이 함께 저장되었는지 확인한다
- **기대 결과**: 질문에서 바로 기록을 시작할 수 있으며, 기록과 질문이 연결되어 저장된다

### TC-002-03-B: 단계 스냅샷의 불변성

- **검증 대상**: AC-002-03
- **사전 조건**: 임신 중 아이로 기록을 1건 이상 작성한 상태
- **테스트 단계**:
  1. 임신 중 상태에서 작성한 기록의 단계 표시를 확인한다 (예: `임신 28주차`)
  2. 출산 전환을 수행한다 (PRD-006 AC-006-06)
  3. 전환 후 일기 탭에서 해당 기록을 다시 연다
  4. 기록에 표시되는 단계가 여전히 작성 당시 값인지 확인한다
  5. 전환 이후 새로 작성한 기록은 생후 나이 단계로 저장되는지 확인한다
- **기대 결과**: 작성 당시 단계는 아이 단계가 바뀌어도 변하지 않으며, 전환 전후 기록이 각각의 축으로 구분된다

### TC-002-03-C: 기준값 정정 시 스냅샷 재계산

- **검증 대상**: AC-002-03 (ENG-013 재계산 트리거 T1·T2)
- **사전 조건**: 임신 중 아이로 기록을 여러 건 작성한 상태
- **테스트 단계**:
  1. 일기 탭에서 기존 기록들의 단계 칩을 기록해 둔다 (예: `임신 20주차`)
  2. 설정에서 해당 아이의 **출산 예정일을 2주 앞당겨** 수정한다
  3. 일기 탭으로 돌아와 기존 기록들의 단계 칩이 **정정된 값으로 재계산**되었는지 확인한다
  4. 기록의 **작성일 자체는 변하지 않았는지** 확인한다
  5. 예정일을 원래 값으로 되돌린 뒤 칩이 최초 값으로 복원되는지 확인한다 (멱등성)
  6. **출산 전환을 수행한 뒤** 임신기 기록의 칩이 여전히 `임신 N주차`인지 확인한다 — 전환은 재계산 트리거가 **아니다**
- **기대 결과**: 기준값 정정은 같은 축 기록의 스냅샷을 재계산하지만, 출산 전환과 시간 경과는 스냅샷을 바꾸지 않는다

### TC-002-04: 질문 알림 발송 테스트

- **검증 대상**: AC-002-04
- **사전 조건**: 알림 권한이 허용된 상태
- **테스트 단계**:
  1. 알림 발송 시간을 설정한다
  2. 설정한 시간에 푸시 알림이 도착하는지 확인한다
  3. 알림이 참조하는 질문이 활성 아이의 단계에 맞는 질문인지 확인한다
  4. 알림을 탭하여 질문 화면으로 이동하는지 확인한다
  5. 알림 시간을 변경하고 변경된 시간에 알림이 오는지 확인한다
  6. 아이가 둘 이상인 경우에도 알림이 1회만 발송되는지 확인한다
- **기대 결과**: 설정된 시간에 활성 아이 단계에 맞는 질문 알림이 1회 발송되며, 탭하면 질문 화면으로 이동한다

### TC-002-05-A: 단계 산출 불가 시 폴백

- **검증 대상**: AC-002-05
- **사전 조건**: 온보딩에서 출산 예정일을 "아직 정해지지 않았어요"로 건너뛴 사용자 (PRD-006 AC-006-02)
- **테스트 단계**:
  1. 홈 화면으로 이동한다
  2. 오늘의 질문 카드가 **정상 표시**되는지 확인한다 (오류·빈 상태가 아님)
  3. 단계 표시(주차 배지)가 **생략**되어 있는지 확인한다
  4. 질문 내용이 특정 주차를 전제하지 않는 공용 문항인지 확인한다
  5. 기록 진입 버튼이 정상 동작하는지 확인한다
- **기대 결과**: 단계 표시만 생략된 채 질문 경험은 정상 동작하며, 사용자에게 결함으로 보이지 않는다

### TC-002-05-B: 기준값 입력 후 단계별 풀 복귀

- **검증 대상**: AC-002-05
- **사전 조건**: TC-002-05-A 상태(예정일 미입력)의 사용자
- **테스트 단계**:
  1. 설정에서 출산 예정일을 입력한다
  2. 홈 화면으로 돌아온다
  3. 단계 표시가 나타나는지 확인한다
  4. 다음 질문부터 해당 주차 풀에서 선택되는지 확인한다
- **기대 결과**: 기준값 입력 후 단계 표시가 복구되고 질문이 단계별 풀로 전환된다
