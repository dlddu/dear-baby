# TEST-002: 매일 다른 질문 알림 테스트

## 대상 PRD

PRD-002: 매일 다른 질문 알림

## 테스트 케이스

### TC-002-01: 오늘의 질문 표시 테스트

- **검증 대상**: AC-002-01
- **사전 조건**: 사용자가 출산 예정일을 등록한 상태
- **테스트 단계**:
  1. 홈 화면으로 이동한다
  2. 오늘의 질문 카드가 표시되는지 확인한다
  3. 임신 주차 정보가 함께 표시되는지 확인한다
  4. 질문 안내 문구가 포함되어 있는지 확인한다
- **기대 결과**: 오늘의 질문 카드가 임신 주차 정보와 함께 홈 화면에 표시된다

### TC-002-02: 임신 주차별 질문 매칭 테스트

- **검증 대상**: AC-002-02
- **사전 조건**: 출산 예정일이 등록된 상태
- **테스트 단계**:
  1. 현재 임신 주차를 확인한다
  2. 제공된 질문이 해당 주차에 적합한지 확인한다
  3. 다음 날 다시 접속하여 다른 질문이 제공되는지 확인한다
  4. 이전에 받은 질문이 반복되지 않는지 확인한다
- **기대 결과**: 임신 주차에 맞는 질문이 매일 중복 없이 제공된다

### TC-002-03: 질문에서 기록 연결 테스트

- **검증 대상**: AC-002-03
- **사전 조건**: 오늘의 질문이 표시된 상태
- **테스트 단계**:
  1. 질문 카드에서 음성 기록 또는 텍스트 기록 버튼을 확인한다
  2. 기록 버튼을 탭하여 기록을 작성한다
  3. 저장된 기록에 해당 질문이 함께 저장되었는지 확인한다
- **기대 결과**: 질문에서 바로 기록을 시작할 수 있으며, 기록과 질문이 연결되어 저장된다

### TC-002-04: 질문 알림 발송 테스트

- **검증 대상**: AC-002-04
- **사전 조건**: 알림 권한이 허용된 상태
- **테스트 단계**:
  1. 알림 발송 시간을 설정한다
  2. 설정한 시간에 푸시 알림이 도착하는지 확인한다
  3. 알림을 탭하여 질문 화면으로 이동하는지 확인한다
  4. 알림 시간을 변경하고 변경된 시간에 알림이 오는지 확인한다
- **기대 결과**: 설정된 시간에 알림이 발송되며, 탭하면 질문 화면으로 이동한다
