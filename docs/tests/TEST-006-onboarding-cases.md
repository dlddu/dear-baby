# TEST-006: 케이스 분기 온보딩 및 아이 컨텍스트 관리 테스트

## 대상 PRD

PRD-006: 케이스 분기 온보딩 및 아이 컨텍스트 관리

## 테스트 케이스

### TC-006-01: 케이스 분기 — 임신 O · 양육 X (Case A)

- **검증 대상**: AC-006-01
- **사전 조건**: 회원가입 직후 첫 진입 상태
- **테스트 단계**:
  1. "현재 임신 중이신가요?" 화면에서 [예]를 선택한다
  2. "이미 태어난 아이가 있나요?" 화면에서 [아니요]를 선택한다
  3. 다음으로 표시되는 입력 화면을 확인한다
- **기대 결과**: Case A 의 임신 아이 수 선택 화면으로 이동한다

### TC-006-02: 케이스 분기 — 임신 O · 양육 O (Case B)

- **검증 대상**: AC-006-01
- **사전 조건**: 회원가입 직후 첫 진입 상태
- **테스트 단계**:
  1. "현재 임신 중이신가요?" 화면에서 [예]를 선택한다
  2. "이미 태어난 아이가 있나요?" 화면에서 [예]를 선택한다
  3. 다음으로 표시되는 입력 화면을 확인한다
- **기대 결과**: Case B 의 안내 ① (B0) 화면으로 이동한 뒤 [네, 시작할게요] 로 양육 중 아이 수 입력(B1)으로 진입한다 (양육 → 임신 순서)

### TC-006-03: 케이스 분기 — 임신 X · 양육 O (Case C)

- **검증 대상**: AC-006-01
- **사전 조건**: 회원가입 직후 첫 진입 상태
- **테스트 단계**:
  1. "현재 임신 중이신가요?" 화면에서 [아니요]를 선택한다
  2. "이미 태어난 아이가 있나요?" 화면에서 [예]를 선택한다
- **기대 결과**: Case C 의 양육 중 아이 수 입력 화면으로 이동한다

### TC-006-04: Case A — 단태 입력 후 홈 진입

- **검증 대상**: AC-006-02
- **사전 조건**: TC-006-01 종료 직후
- **테스트 단계**:
  1. 임신 아이 수에서 [단태]를 선택한다
  2. 태아 정보(태명·성별·임신 주차·예정일)를 입력한다
  3. 기록 목적을 복수 선택한다
  4. 다음 화면으로 이동한다
- **기대 결과**: 홈 화면으로 진입하며, 입력한 태아 정보가 활성 컨텍스트로 표시된다

### TC-006-05: Case B — 양육 → 임신 순서로 입력 진행

- **검증 대상**: AC-006-03
- **사전 조건**: TC-006-02 종료 직후 (B0 안내 ① 화면)
- **테스트 단계**:
  1. B0 [네, 시작할게요] 로 양육 단계로 진입한다
  2. B1 양육 중 아이 수를 [1명] 또는 [2명]으로 선택한다
  3. 양육 아이마다 B2 (이름·성별·생년월일·한줄 소개) → B2-Purpose (양육 톤 칩 8 종에서 다중 선택) 를 1:1 로 거친다
  4. 마지막 양육 아이의 B2-Purpose [다음] 에서 B3 안내 ② 로 진입한다
  5. B4 임신 중 아이 수를 선택하고 각 태아별 B5 (예정일·태명·성별·임신 주차) 를 입력한다
  6. 마지막 태아의 [다음] 에서 B6 기록 목적 화면이 노출되고, 임신 톤 칩 8 종 단일 그리드에서 다중 선택한다 (다태인 경우 안내 카피로 "모든 태아에게 동일하게 적용된다"가 노출됨)
  7. B6 [시작하기 ✨] 를 누른다
- **기대 결과**:
  - 양육 입력(B1·B2·B2-Purpose)이 임신 입력(B4·B5·B6)보다 먼저 표시된다
  - 양육 아이의 기록 목적은 정보 입력 직후 1:1 화면에서 아이별로 다르게 받고, 태아의 기록 목적은 마지막에 1회만 묻고 모든 태아 행에 동일하게 복제된다
  - [시작하기 ✨] 시 POST `/me/onboarding/case-b` 한 번으로 양육+임신 양쪽 행과 첫 태아의 예정일이 영속화되고, 홈 화면으로 진입한다

### TC-006-06: Case C — 다자녀 양육자 입력

- **검증 대상**: AC-006-04
- **사전 조건**: TC-006-03 종료 직후
- **테스트 단계**:
  1. 양육 중 아이 수를 [2명]으로 선택한다
  2. 첫째 아이 정보를 입력한다
  3. 둘째 아이 정보를 입력한다
  4. 기록 목적을 복수 선택한다
- **기대 결과**: 두 아이 정보가 각각 저장되고 홈 화면으로 진입하며, 다자녀 사용자이므로 아이 전환 탭이 노출된다 (AC-006-08과 연계 검증)

### TC-006-07: 출산 D-7 푸시 알림 발송

- **검증 대상**: AC-006-05
- **사전 조건**: Case A 사용자, 푸시 알림 권한 허용, 출산 예정일이 정확히 D-7 (시뮬레이션 시계 사용)
- **테스트 단계**:
  1. 시뮬레이션 시계를 D-7 시점으로 이동시킨다
  2. 알림 발송을 트리거한다 (스케줄러 동작 확인)
  3. 단말의 알림 센터를 확인한다
- **기대 결과**:
  - "곧 만날 날이 다가오고 있어요. 아이가 태어났나요?" 의미의 알림이 1회 발송된다
  - 다태아 임신인 경우에도 알림은 1회만 발송된다

### TC-006-08: 출산 확인 팝업 — [네, 태어났어요] 선택 시 양육자 모드 전환

- **검증 대상**: AC-006-06
- **사전 조건**: Case A 사용자, 임신 단태아, 현재 시점이 출산 예정일 당일 이후
- **테스트 단계**:
  1. 앱을 진입한다
  2. 출산 확인 팝업이 표시되는지 확인한다
  3. [네, 태어났어요] 를 선택한다
  4. 실제 출생일 입력 화면에서 어제 날짜를 입력한다
  5. 저장 후 홈 화면을 확인한다
- **기대 결과**:
  - 팝업이 정상 표시된다
  - 태아 정보가 아이 정보로 자동 변환된다 (태명 → 이름 마이그레이션 안내 포함)
  - 임신 주차 표시가 양육 일수 표시로 갱신된다

### TC-006-09: 출산 확인 팝업 — 다태아 출생일 개별 입력

- **검증 대상**: AC-006-06
- **사전 조건**: Case A 다태아 사용자, 예정일 당일 이후
- **테스트 단계**:
  1. 앱을 진입하여 출산 확인 팝업에서 [네, 태어났어요] 를 선택한다
  2. 실제 출생일 입력 화면에서 각 아이별로 출생일을 입력한다
- **기대 결과**: 각 아이의 출생일이 개별적으로 저장되고, 모두 양육자 데이터로 변환된다

### TC-006-10: 출산 확인 팝업 — [아직이에요] 선택 시 1주 후 재질문

- **검증 대상**: AC-006-06
- **사전 조건**: Case A 사용자, 예정일 당일
- **테스트 단계**:
  1. 앱 진입 시 표시되는 팝업에서 [아직이에요] 를 선택한다
  2. 시뮬레이션 시계로 6일 뒤로 이동, 앱을 다시 진입한다
  3. 시뮬레이션 시계로 7일 뒤로 이동, 앱을 다시 진입한다
- **기대 결과**:
  - 6일 시점에는 팝업이 표시되지 않는다
  - 7일 시점에는 팝업이 다시 표시된다

### TC-006-11: 출산 D+14 이후 자동 팝업 중단 및 설정 배너 노출

- **검증 대상**: AC-006-07
- **사전 조건**: Case A 사용자, [아직이에요] 를 D+13까지 반복 선택한 상태
- **테스트 단계**:
  1. 시뮬레이션 시계를 D+14 로 이동시킨다
  2. 앱을 진입하여 홈 화면을 확인한다 (자동 팝업 노출 여부)
  3. 설정 탭으로 이동한다
- **기대 결과**:
  - D+14 이후에는 자동 팝업이 더 이상 표시되지 않는다
  - 설정 탭에 "양육자 모드로 전환" 배너가 표시된다
  - 배너 탭 시 실제 출생일 입력 화면으로 이동한다

### TC-006-12: 다자녀 — 홈 상단 아이 전환 탭 노출 조건

- **검증 대상**: AC-006-08
- **사전 조건**: 두 사용자 계정 (단일 아이 / 다자녀)
- **테스트 단계**:
  1. 단일 아이 사용자로 홈에 진입한다
  2. 다자녀 사용자(Case B 또는 다자녀 양육자)로 홈에 진입한다
- **기대 결과**:
  - 단일 아이 사용자의 홈 상단에는 전환 탭이 노출되지 않는다
  - 다자녀 사용자의 홈 상단에는 [◀ 아이 이름/태명 ▶] 형태의 전환 탭이 노출된다

### TC-006-13: 다자녀 — 화살표 탭으로 활성 컨텍스트 전환 및 순환

- **검증 대상**: AC-006-08
- **사전 조건**: Case B 사용자(양육 1명 + 임신 1명) 또는 다자녀 양육자
- **테스트 단계**:
  1. 홈 진입 후 현재 활성 아이를 확인한다
  2. ▶ 화살표를 탭하여 다음 아이로 전환한다
  3. 마지막 아이까지 ▶ 를 반복 탭한다
  4. 마지막 아이에서 ▶ 를 한 번 더 탭한다
  5. ◀ 화살표로 좌측 순환을 확인한다
- **기대 결과**:
  - 화살표 탭마다 다음/이전 아이의 이름·태명으로 라벨이 갱신된다
  - 마지막 아이에서 ▶ 탭 시 첫 아이로 순환한다
  - 첫 아이에서 ◀ 탭 시 마지막 아이로 순환한다
  - 임신 중 아이와 양육 중 아이가 섞여 있어도 단일 리스트로 순회된다

### TC-006-14: 다자녀 — 활성 아이 기준으로 모든 탭 재구성

- **검증 대상**: AC-006-09
- **사전 조건**: 다자녀 사용자, 각 아이별로 최소 1개 이상의 기록이 존재
- **테스트 단계**:
  1. 홈 탭에서 첫째 아이를 활성으로 둔 채 표시 내용을 확인한다
  2. 일기 탭으로 이동하여 표시되는 기록 목록을 확인한다
  3. 자서전 탭으로 이동하여 표시되는 책을 확인한다
  4. 홈으로 돌아와 둘째 아이로 전환한다
  5. 일기/자서전 탭을 다시 확인한다
  6. 커뮤니티 탭으로 이동하여 컨텍스트(임신/양육·주차)를 확인한다
- **기대 결과**:
  - 일기 탭: 활성 아이의 기록만 표시된다
  - 자서전 탭: 활성 아이의 책만 표시된다
  - 커뮤니티 탭: 활성 아이의 케이스/주차에 맞는 컨텍스트로 진입한다
  - 활성 아이 변경 시 모든 탭이 즉시 갱신된다

### TC-006-15: 다자녀 — 활성 아이가 세션 간 유지

- **검증 대상**: AC-006-09
- **사전 조건**: 다자녀 사용자, 둘째 아이를 활성으로 선택한 상태
- **테스트 단계**:
  1. 둘째 아이를 활성으로 둔 채 앱을 종료한다
  2. 앱을 다시 실행한다
- **기대 결과**: 앱 재실행 후에도 둘째 아이가 활성 컨텍스트로 유지된다

### TC-006-16: 다자녀 — 새 기록 작성 시 기본 대상 아이가 활성 아이

- **검증 대상**: AC-006-09
- **사전 조건**: 다자녀 사용자, 둘째 아이가 활성
- **테스트 단계**:
  1. 새 기록 작성 화면을 연다
  2. 대상 아이가 자동으로 둘째 아이로 지정되어 있는지 확인한다
  3. 대상 아이를 셋째 아이로 변경할 수 있는지 확인한다
- **기대 결과**: 기본값은 활성 아이(둘째)이며, 사용자가 다른 아이로 변경할 수 있다

### TC-006-17: 설정 탭 — 임신 중 아이 추가 (우선순위 낮음)

- **검증 대상**: AC-006-10
- **사전 조건**: Case C 사용자(양육 중 아이 1명)
- **테스트 단계**:
  1. 설정 탭의 "아이 추가" 진입점을 탭한다
  2. 임신 / 양육 분기에서 [임신 중] 을 선택한다
  3. Case A 의 태아 정보 입력 흐름을 따라간다
  4. 입력 완료 후 홈으로 돌아간다
- **기대 결과**:
  - 임신 정보가 추가 저장된다
  - 홈 상단에 아이 전환 탭이 새로 노출되며, 추가된 태아가 리스트에 합류한다

### TC-006-18: 설정 탭 — 양육 중 아이 추가 (우선순위 낮음)

- **검증 대상**: AC-006-10
- **사전 조건**: Case A 사용자(임신 중 아이 1명)
- **테스트 단계**:
  1. 설정 탭의 "아이 추가" 진입점을 탭한다
  2. 임신 / 양육 분기에서 [양육 중] 을 선택한다
  3. Case C 의 아이 정보 입력 흐름을 따라간다
- **기대 결과**:
  - 양육 아이 정보가 추가 저장된다
  - 사용자의 케이스가 사실상 Case B 와 동등하게 동작한다 (양육 + 임신 컨텍스트 공존)
  - 아이 전환 탭이 노출된다

### TC-006-19: 푸시 권한 미허용 시 인앱 팝업은 정상 동작

- **검증 대상**: 비기능 요구사항 (푸시 미허용 시)
- **사전 조건**: Case A 사용자, 푸시 알림 권한 거부, 예정일 당일 이후
- **테스트 단계**:
  1. 푸시 알림 권한을 거부한 상태로 앱에 진입한다
- **기대 결과**:
  - D-7 푸시는 발송되지 않는다 (단말 알림 센터에 노출되지 않음)
  - 앱 진입 시 출산 확인 팝업(AC-006-06)은 정상 표시된다
