## 테스트 케이스

### TC-008-01-A: 임신 모드 — 주차 단위 그룹 + 역시간순 정렬

- **검증 대상**: AC-008-01
- **사전 조건**: 활성 아이가 임신 중이며, 서로 다른 주차에 작성된 일기가 4건 이상 누적된 사용자
- **테스트 단계**:
  1. 일기 탭으로 진입한다
  2. 상단의 그룹 헤더와 일기 카드들의 정렬 순서를 확인한다
- **기대 결과**: 가장 큰 주차(가장 최근) 그룹이 상단에 위치하며, 같은 그룹 내 일기는 작성 일자 역순으로 표시된다

### TC-008-01-B: 양육자 모드 — 개월수 단위 그룹

- **검증 대상**: AC-008-01
- **사전 조건**: 활성 아이가 양육 중이며, 출생일 이후 서로 다른 개월에 작성된 일기가 3건 이상 있는 사용자
- **테스트 단계**:
  1. 일기 탭으로 진입한다
  2. 그룹 헤더 형식을 확인한다
- **기대 결과**: 그룹 헤더가 `D+3개월`, `D+2개월` 등 개월수 형식으로 표시되며 최근 개월이 상단에 위치한다

### TC-008-01-C: 같은 날 다중 일기 — 시간 역순 별도 카드

- **검증 대상**: AC-008-01
- **사전 조건**: 동일 일자에 2건 이상의 일기가 작성된 사용자
- **테스트 단계**:
  1. 일기 탭으로 진입한다
  2. 해당 일자의 카드 개수와 정렬을 확인한다
- **기대 결과**: 같은 날 작성된 일기는 모두 별도 카드로 노출되며, 작성 시각 역순으로 정렬된다 (일자 단위로 머지되지 않는다)

### TC-008-02-A: 카드 — 날짜·미디어 아이콘·미리보기 표시

- **검증 대상**: AC-008-02
- **사전 조건**: 본문 텍스트와 음성·사진이 함께 첨부된 일기가 1건 이상 존재
- **테스트 단계**:
  1. 일기 탭의 해당 카드를 확인한다
  2. 1행에 작성 날짜와 미디어 아이콘(🎤, 📷)이 모두 표시되는지 확인한다
  3. 2행에 본문 미리보기 텍스트가 1~2줄로 표시되고, 길면 말줄임표로 잘리는지 확인한다
- **기대 결과**: 카드 1행은 `날짜 + 미디어 아이콘들`, 2행은 본문 미리보기 텍스트가 표시된다

### TC-008-02-B: 본문 없는 미디어 전용 일기 — 미리보기 대체 표시

- **검증 대상**: AC-008-02
- **사전 조건**: 본문 텍스트가 없고 사진 2장만 첨부된 일기가 1건 존재
- **테스트 단계**:
  1. 일기 탭에서 해당 카드의 2행을 확인한다
- **기대 결과**: 미리보기 자리에 `사진 2장` 형태의 미디어 종류 설명이 표시된다 (본문 영역이 비어 있지 않다)

### TC-008-03-A: 다자녀 — 활성 아이 변경 시 즉시 갱신

- **검증 대상**: AC-008-03
- **사전 조건**: 2명 이상의 활성 아이를 보유한 사용자 (Case B 등), 각 아이에 일기가 1건 이상 작성됨
- **테스트 단계**:
  1. 일기 탭으로 진입하여 첫 번째 아이의 일기 목록을 확인한다
  2. 상단의 아이 전환 탭으로 두 번째 아이로 전환한다
  3. 목록 갱신을 확인한다
- **기대 결과**: 아이 전환 즉시 일기 목록이 두 번째 아이의 일기로 갱신된다 (재진입 없이도 갱신, 헤더에 두 번째 아이 이름 표시)

### TC-008-03-B: 단일 아이 — 아이 전환 UI 없음

- **검증 대상**: AC-008-03
- **사전 조건**: 단일 아이(Case A 단일 또는 Case C 단일) 사용자
- **테스트 단계**:
  1. 일기 탭으로 진입한다
  2. 상단의 아이 전환 UI 존재 여부를 확인한다
- **기대 결과**: 좌우 화살표 형태의 아이 전환 UI 가 노출되지 않으며, 단일 아이 컨텍스트로 표시된다

### TC-008-04-A: 카드 탭 → 상세 화면 진입

- **검증 대상**: AC-008-04
- **사전 조건**: 일기 목록에 1건 이상의 카드가 존재
- **테스트 단계**:
  1. 일기 탭으로 진입한다
  2. 임의의 카드를 탭한다
  3. 상세 화면에서 본문 전체, 첨부 미디어, 작성 일시를 확인한다
- **기대 결과**: 상세 화면으로 전환되며 전체 본문·모든 미디어·작성 일시가 표시된다

### TC-008-04-B: 상세 → 뒤로 가기 시 스크롤 위치 복귀

- **검증 대상**: AC-008-04
- **사전 조건**: 일기가 10건 이상 누적되어 목록 스크롤이 필요한 상태
- **테스트 단계**:
  1. 일기 탭에서 화면 중간 정도로 스크롤한다
  2. 한 카드를 탭하여 상세로 진입한다
  3. 상세 화면에서 뒤로 가기를 수행한다
- **기대 결과**: 일기 목록으로 복귀했을 때 이전 스크롤 위치가 그대로 유지된다 (목록 최상단으로 리셋되지 않는다)

### TC-008-05-A: 빈 상태 — 카피와 CTA 표시

- **검증 대상**: AC-008-05
- **사전 조건**: 활성 아이의 일기가 0건인 사용자 (예: 온보딩 직후)
- **테스트 단계**:
  1. 일기 탭으로 진입한다
  2. 화면을 확인한다
- **기대 결과**: 일러스트(또는 아이콘)와 안내 카피, **홈으로 가기** CTA 가 표시된다

### TC-008-05-B: 빈 상태에서 하단 네비게이션 정상 노출

- **검증 대상**: AC-008-05
- **사전 조건**: TC-008-05-A 와 동일
- **테스트 단계**:
  1. 빈 상태 화면에서 하단 네비게이션을 확인한다
- **기대 결과**: 5탭 하단 네비게이션 바가 PRD-007 AC-007-10 정의대로 정상 표시된다

### TC-008-05-C: 빈 상태 → 홈 CTA 탭 시 홈으로 이동

- **검증 대상**: AC-008-05
- **사전 조건**: 빈 상태가 노출된 상태
- **테스트 단계**:
  1. **홈으로 가기** CTA 버튼을 탭한다
- **기대 결과**: 홈 탭(PRD-007) 화면으로 이동하며, 하단 네비게이션의 활성 탭이 홈으로 전환된다
