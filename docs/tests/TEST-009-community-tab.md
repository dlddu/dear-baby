# TEST-009: 커뮤니티 탭 테스트

## 대상 PRD

PRD-009: 커뮤니티 탭 — 공개 기록 기반 공감 커뮤니티 (2026-08-05 확정)

> 구 TEST-007의 TC-007-08(피드 카드)·TC-007-09-A(비공개 미노출)·TC-007-09-B(정렬)는
> 명세 이관에 따라 본 문서로 흡수되었다: 카드·빈 상태 검증은 TC-009-14-A/B가 승계하고,
> 노출·정렬 검증은 ENG-007~010 확정 후 ENG 매핑 검증으로 재정의한다 (AC 검증 아님).
> 피드의 노출 풀·정렬·페이지네이션 자체는 본 문서의 검증 범위가 아니다.

## 테스트 케이스

### TC-009-01: 콘텐츠 출처 — 공개 기록만, 글쓰기 없음

- **검증 대상**: AC-009-01
- **사전 조건**: 계정 A에 공개 기록 1건·비공개 기록 1건·임시 저장 1건 존재
- **테스트 단계**:
  1. 계정 B로 커뮤니티 탭에 진입한다
  2. 계정 A의 공개 기록만 피드에 보이고 비공개·임시 저장 기록은 보이지 않는지 확인한다
  3. 화면 어디에도 `글쓰기` 버튼이 없는지 확인한다
- **기대 결과**: 공개 기록만 노출되고, 커뮤니티에서 새 글을 작성할 수 없다

### TC-009-02: 메인 화면 구조와 피드 카드 구성

- **검증 대상**: AC-009-02
- **사전 조건**: 공개 기록(질문답변 1건, 자유일기 1건) 존재
- **테스트 단계**:
  1. 커뮤니티 탭 진입 후 위에서부터 헤더 → 유사 시기 영역 → 오늘의 질문 카드 → 타입 필터 → 피드 순서인지 확인한다
  2. 피드 카드에 마스킹 표시명·아이 현황·타입·질문 텍스트(질문답변)/제목(자유일기)·본문 미리보기·공감 수·댓글 수가 표시되는지 확인한다
  3. 카드를 탭해 상세 화면으로 이동하는지 확인한다
- **기대 결과**: 화면 구조와 카드 요소가 명세대로 표시되고 상세로 진입한다

### TC-009-03: 상단 상태값 표시와 아이 전환 갱신

- **검증 대상**: AC-009-03
- **사전 조건**: 다자녀 계정(임산부 태아 1 + 양육 아이 1)
- **테스트 단계**:
  1. 임신 중 태아를 활성으로 두고 커뮤니티 진입 — 상단에 `임신 N주차` 표시를 확인한다
  2. 홈에서 양육 아이로 전환 후 커뮤니티 재진입 — `생후 N개월` 표시로 갱신되는지 확인한다
  3. 시기 필터를 사용자가 직접 변경하는 UI가 없는지 확인한다
- **기대 결과**: 활성 아이 기준 상태값이 표시·갱신되고 수동 필터는 제공되지 않는다

### TC-009-04-A: 질문 카드 CTA — 미답변 분기

- **검증 대상**: AC-009-04
- **사전 조건**: 오늘의 질문에 아직 답변하지 않은 계정
- **테스트 단계**:
  1. 커뮤니티의 오늘의 질문 카드에서 질문 텍스트가 홈의 오늘의 질문과 동일한지 확인한다
  2. CTA `다른 엄마들의 답변 보기`를 탭한다
- **기대 결과**: 질문 답변 화면으로 이동한다

### TC-009-04-B: 질문 카드 CTA — 비공개 답변 분기

- **검증 대상**: AC-009-04
- **사전 조건**: 오늘의 질문에 비공개로 답변한 계정
- **테스트 단계**:
  1. CTA를 탭한다
- **기대 결과**: 공개 전환 유도 팝업이 노출된다

### TC-009-04-C: 질문 카드 CTA — 공개 답변 분기

- **검증 대상**: AC-009-04
- **사전 조건**: 오늘의 질문에 공개로 답변한 계정
- **테스트 단계**:
  1. CTA를 탭한다
- **기대 결과**: 같은 질문 답변 모아보기 화면으로 이동한다

### TC-009-05-A: 모아보기 — 상호 공개 열람 권한

- **검증 대상**: AC-009-05
- **사전 조건**: 같은 질문에 공개 답변한 타 계정 존재
- **테스트 단계**:
  1. 미답변 상태로 모아보기 진입 시도 — 열람 불가 확인
  2. 비공개로 답변 후 진입 시도 — 안내 문구·`내 답변 공개하고 보기`/`나중에 볼게요` 버튼 확인
  3. `내 답변 공개하고 보기` 탭 — 내 답변이 `public` 전환되고 목록이 열리는지 확인
- **기대 결과**: 상태별 열람 권한 표가 그대로 동작하고, 공개 전환 시 목록 진입과 피드 노출이 함께 이뤄진다

### TC-009-05-B: 모아보기 — 재비공개 시 권한 즉시 소멸

- **검증 대상**: AC-009-05
- **사전 조건**: TC-009-05-A 완료 상태(내 답변 공개)
- **테스트 단계**:
  1. 내 답변을 비공개로 전환한다 (일기 탭 또는 상세 화면)
  2. 같은 질문 모아보기 재진입을 시도한다
- **기대 결과**: 열람 불가 상태로 돌아가며 공개 전환 유도가 다시 표시된다 (과거 공개 이력은 권한을 남기지 않는다)

### TC-009-06: 콘텐츠 타입 필터

- **검증 대상**: AC-009-06
- **사전 조건**: 공개 질문답변·공개 자유일기 각 1건 이상
- **테스트 단계**:
  1. 기본 선택이 `전체`인지 확인한다
  2. `질문답변` 선택 — 질문답변만 노출 확인
  3. `자유일기` 선택 — 자유일기만 노출 확인
- **기대 결과**: 필터 선택에 따라 해당 타입만 노출된다

### TC-009-07-A: 게시글 상세 — 표시 요소와 본인 글 관리

- **검증 대상**: AC-009-07
- **사전 조건**: 본인 공개 기록 1건, 타인 공개 기록 1건
- **테스트 단계**:
  1. 타인 글 상세 — 마스킹 표시명·아이 현황·작성일·본문 전체·공감·댓글·신고 요소를 확인하고, 관리 기능이 없는지 확인한다
  2. 본인 글 상세 — 공개/비공개 전환·본문 수정·삭제 기능이 제공되는지 확인한다
- **기대 결과**: 표시 요소가 명세대로 나타나고 관리 기능은 본인 글에만 제공된다

### TC-009-07-B: 공개 수명주기 — 전환 보존·삭제 소멸

- **검증 대상**: AC-009-07
- **사전 조건**: 공감·댓글이 달린 본인 공개 기록
- **테스트 단계**:
  1. 비공개 전환 — 피드·모아보기에서 즉시 제거 확인
  2. 재공개 — 기존 공감·댓글 수가 복원되는지 확인
  3. 삭제 — 확인 모달에 `받은 공감과 댓글도 함께 삭제됩니다.` 문구 확인 후 삭제, 커뮤니티 전 화면에서 게시글·공감·댓글이 소멸하고 복구 경로가 없는지 확인
- **기대 결과**: 비공개=보존·복원, 삭제=소멸의 대칭이 동작한다

### TC-009-08: 공감 — 토글과 본인 제한 (경로 무관)

- **검증 대상**: AC-009-08
- **사전 조건**: 타인 공개 기록 1건, 본인 공개 기록 1건(댓글 포함)
- **테스트 단계**:
  1. 타인 글 공감 — 카운트 +1, 재탭 시 취소(−1), 중복 불가 확인
  2. 본인 글에 피드 경유·일기 탭 경유 상세에서 각각 공감 시도 — 불가 확인
  3. 본인 댓글에 공감 시도 — 불가 확인
- **기대 결과**: 공감 토글이 동작하고, 본인 글·본인 댓글 공감은 도달 경로와 무관하게 불가하다

### TC-009-09: 댓글/대댓글 — 1depth·작성자 표시

- **검증 대상**: AC-009-09
- **사전 조건**: 타인 공개 기록 1건
- **테스트 단계**:
  1. 댓글 작성 — 작성자가 마스킹 표시명으로 나타나는지 확인
  2. 원글 작성자 계정으로 댓글 작성 — `작성자` 배지 확인
  3. 댓글에 대댓글 작성 — 성공. 대댓글에 다시 답글 시도 — 입력 수단이 없는지 확인
  4. 본인 댓글 삭제 — 성공. 타인 댓글에는 삭제 수단이 없는지 확인
- **기대 결과**: 1depth 제한·작성자 표시·배지·본인만 삭제가 명세대로 동작한다

### TC-009-10: 개인정보 보호 — 마스킹 표시명과 비노출 항목

- **검증 대상**: AC-009-10
- **사전 조건**: 이메일 로컬파트가 5자 이상인 계정 A(예: `seoyeon1@…`)와 4자 이하인 계정 B(예: `min@…`), 각각 태명·사진 포함 공개 기록
- **테스트 단계**:
  1. 계정 A의 글에서 표시명이 `앞 3자+***+끝 1자`(`seo***1`)인지 확인한다
  2. 계정 B의 글에서 표시명이 `첫 1자+***`(`m***`)인지 확인한다
  3. 카드·상세 어디에도 실명·태명·출산 예정일·생년월일·이메일 원문·도메인이 없는지 확인한다
  4. 사진이 첨부된 자유일기의 커뮤니티 노출에서 사진이 제외되고 텍스트만 보이는지 확인한다
- **기대 결과**: 마스킹 규칙이 길이 분기 포함 정확히 적용되고, 비노출 항목과 사진이 커뮤니티에 나타나지 않는다

### TC-009-11: 신고 — 접수·중복 방지·신고자 숨김

- **검증 대상**: AC-009-11
- **사전 조건**: 타인 공개 기록과 그 댓글 각 1건
- **테스트 단계**:
  1. 게시글 신고 진입 — 사유 5종 선택지 확인, 1종 선택 제출 — 토스트 `신고가 접수되었어요` 확인
  2. 같은 게시글 재신고 시도 — `이미 신고한 기록이에요` 안내 확인
  3. 신고한 게시글이 내 피드에서 숨김 처리되는지, 타 계정에는 그대로 보이는지 확인
  4. 댓글 `⋯` 메뉴로 동일 접수 흐름을 확인
- **기대 결과**: 접수 플로우·중복 방지·신고자 화면 숨김이 동작한다 (운영 처리는 범위 밖)

### TC-009-13: 빈 상태/예외 상태 문구

- **검증 대상**: AC-009-13
- **사전 조건**: 공개 기록 0건 환경, 삭제/비공개 전환된 글의 딥링크 확보 가능 환경
- **테스트 단계**:
  1. 공개 기록 0건에서 커뮤니티 피드 — `아직 공개된 기록이 없어요` 확인
  2. 필터 결과 없음 — `해당 조건의 기록이 아직 없어요` 확인
  3. 네트워크 차단 후 진입 — `기록을 불러오지 못했어요. 다시 시도해주세요` 확인
  4. 삭제된 글·비공개 전환된 글 접근 — 각각의 안내 문구 확인
  5. 모아보기 권한 없음 상태 — 안내 문구 확인
- **기대 결과**: 상황별 문구가 표에 정의된 대로 표시된다

### TC-009-14-A: 홈 "다른 엄마들의 기록" 섹션 — 카드 표시

- **검증 대상**: AC-009-14
- **사전 조건**: 공개 기록 3건 이상 존재 (구 TC-007-08 승계)
- **테스트 단계**:
  1. 홈 하단 섹션 타이틀 `다른 엄마들의 기록`과 `>더보기` 링크를 확인한다
  2. 카드가 최대 3개, 가로 스크롤 없이 표시되고 각 카드에 마스킹 표시명·아이 현황·질문 텍스트·본문 미리보기·공감 수가 있는지 확인한다
  3. `>더보기` 탭 — 커뮤니티 탭 진입 확인. 카드 탭 — 해당 기록의 커뮤니티 상세 진입 확인
- **기대 결과**: 홈 섹션이 최대 3개 카드로 표시되고 커뮤니티로 정확히 진입한다

### TC-009-14-B: 홈 섹션 — 빈 상태 (mock 없음)

- **검증 대상**: AC-009-14
- **사전 조건**: 공개 기록 0건 환경 (구 TC-007-09-A의 비공개 미노출 의도 일부 승계)
- **테스트 단계**:
  1. 홈 하단 섹션에 mock 카드가 아닌 빈 카드 + `첫 기록을 공개해보세요` CTA가 표시되는지 확인한다
  2. 비공개 기록만 있는 계정에서도 동일한 빈 상태인지 확인한다
  3. CTA 탭 — 기록 작성 진입 확인
- **기대 결과**: 공개 기록이 없으면 mock data 없이 빈 카드+CTA가 표시되고, 비공개 기록은 섹션에 나타나지 않는다
