# Typography — 타이포그래피

## Type Scale

| 레벨 | 용도 | 크기 | 굵기 | 예시 |
|------|------|------|------|------|
| **H1** | 앱 타이틀 | 28px | 700 | DearBaby |
| **H2** | 섹션 타이틀 | 20px | 700 | 이번 주 기록 |
| **H2 Serif** | 감성 타이틀 (Serif) | 22px | 700 | 지금 임신 중이신가요? |
| **H3** | 카드 타이틀 | 17px | 600 | 오늘의 질문 |
| **Body** | 본문 | 15px | 400 | 아기에게 전하고 싶은 말을 들려주세요 |
| **Caption** | 캡션 | 13px | 400 | 3월 22일 |
| **Badge** | 배지 | 12px | 600 | 임신 17주 3일 |

## Font Family

### 영문 (로고)

Serif 계열 — **Playfair Display** 또는 커스텀 세리프. 우아하고 클래식한 느낌.

### 한글 (UI)

**Pretendard** 또는 **Noto Sans KR** — 둥근 느낌의 고딕체. 가독성 우선.

### 한글 (캐치프레이즈)

손글씨 또는 세리프 계열 — 감성적 톤 전달용. **마루 부리** 또는 커스텀.

## 사용 원칙

- 헤딩과 본문의 굵기 차이를 명확히 하여 계층 구조를 표현한다 (700 vs 400)
- 배지 텍스트는 12px/600으로 작지만 눈에 띄게 설정한다
- 줄 간격(line-height)은 본문 1.6, 캡션 1.4를 기본으로 한다
- 감성 카피(캐치프레이즈)에는 세리프 또는 손글씨 폰트를 사용하여 기능 UI와 차별화한다
