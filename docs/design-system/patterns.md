# Patterns — UI/UX 패턴

## Layout Patterns

### Greeting → CTA

상단에 감성적 인사말로 사용자를 맞이한 뒤, 바로 아래에 핵심 CTA(음성/텍스트 기록)를 배치하는 패턴.

- Voice-first: 음성 CTA가 항상 왼쪽(primary)에 위치하여 핵심 행동을 유도
- 인사말은 시간대/상황에 맞는 감성 카피 사용

### Contextual Daily Prompt

임신 주차에 맞는 질문을 매일 제공하여 기록을 유도하는 패턴.

- **Context Badge**: 임신 주차를 배지로 표시해 "왜 이 질문인지" 맥락 전달
- **Soft Encouragement**: 질문 아래 부드러운 한 줄 설명으로 기록 허들을 낮춤

### Horizontal Thumbnail Grid

기록을 가로 썸네일 그리드로 나열하는 패턴.

- **Time Grouping**: "이번 주" 단위로 묶어 사용자가 시간 흐름을 인식
- **Progressive Disclosure**: 3개 미리보기 + "더보기"로 정보 과부하 방지

## Content Hierarchy Pattern

홈 화면의 콘텐츠는 위에서 아래로 명확한 우선순위를 따릅니다.

| 순위 | 영역 | 설명 | 컬러 키 |
|------|------|------|---------|
| 1 | Greeting + CTA | 감성 인사 + 핵심 액션 (기록하기) | Coral |
| 2 | Daily Prompt | 맥락 기반 질문으로 기록 유도 | Sage |
| 3 | Recent Records | 이번 주 기록 썸네일 미리보기 | Gold |
| 4 | FAB (Floating) | 화면 하단 고정, 즉시 기록 진입 | Coral |
| 5 | Tab Bar | 홈 / 기록 / 질문 / 마이 네비게이션 | Muted |

## Interaction Patterns

### Voice-First Input

텍스트 입력보다 음성 입력을 우선으로 제시. 임산부의 사용 편의성을 높이고, AI가 음성을 텍스트로 자동 변환.

**플로우**: 🎙 음성 버튼 탭 → 녹음 시작 → AI 텍스트 변환 → 기록 저장

`#접근성` `#편의성` `#AI연동`

### Dual CTA (Primary + Secondary)

동일 목적의 두 가지 입력 방식을 나란히 배치. 왼쪽에 Primary(음성), 오른쪽에 Secondary(텍스트)로 사용자 선택권을 보장.

**플로우**: Primary (왼쪽) | Secondary (오른쪽) → 동일 결과

`#선택권` `#접근성`

### Emotional Micro-copy

기능적 안내 대신 감정을 전달하는 카피 사용. '기록하기' 대신 '아기에게 전하고 싶은 말을 들려주세요'. 사용자의 감정적 동기를 자극.

**플로우**: 감정적 헤드라인 → 공감 서브텍스트 → 행동 유도

`#감성` `#동기부여` `#리텐션`

### AI-Powered Output Pipeline

사용자의 산발적인 기록을 AI가 모아 하나의 서사로 편집 → 실물 책으로 제작하는 가치 전달 파이프라인.

**플로우**: 🎙 음성/텍스트 기록 → 📅 주차별 축적 → ✨ AI 편집·서사 구성 → 📖 실물 책 제작

`#AI` `#가치전환` `#물리적산출물`

### Contextual Badge System

임신 주차를 항상 배지로 표시하여 시간 맥락을 제공. 질문, 기록, AI 편집 모든 화면에서 일관되게 사용.

**플로우**: 임신 주차 계산 → 배지 자동 표시 → 주차별 질문 매칭

`#맥락` `#자동화` `#일관성`

## Feature Card Pattern

서비스 주요 기능 카드는 일관된 구조를 따릅니다.

**구조**: `[Icon: 40×40 circle + bg color]` + `[Title: 15px/600]` + `[Desc: 13px/400 muted]`

| 기능 | 아이콘 배경 | 타이틀 | 설명 |
|------|------------|--------|------|
| 음성 일기 기록 | `#F5C6A8` 🎙 | 음성 일기 기록 | 말하기만 하면 AI가 자동으로 텍스트로 변환해드려요 |
| 매일 다른 질문 알림 | `#C8E0E0` 💬 | 매일 다른 질문 알림 | 아이의 지금 이 시기에 맞는 질문을 매일 보내드려요 |
| AI 편집 & 서사 구성 | `#E8DCC8` ✨ | AI 편집 & 서사 구성 | 흩어진 기록을 하나의 이야기로 아름답게 엮어드려요 |
| 실물 책 제작 | `#D8E0D4` 📖 | 실물 책 제작 | 세상에 하나뿐인 우리 아기 첫 번째 선물 |

## Page Flow & Navigation Pattern

4-tab 구조로 핵심 기능을 구분하며, FAB이 탭 바 위에 떠서 "기록하기" 액션을 항상 접근 가능하게 유지합니다.

- **FAB Override**: 탭 바 위에 FAB을 겹쳐 배치, "기록" 액션을 최우선으로 노출
- **4-Tab Max**: 탭을 4개로 제한하여 한 손 조작 시 모든 탭에 도달 가능
- **Active State**: 활성 탭은 Primary Coral 색상, 비활성은 Muted 톤으로 구분

## Emotional Design Pattern

기능 중심이 아닌 감정 중심의 디자인 언어를 사용합니다.

| 기능적 표현 | 감성적 표현 | 원칙 |
|------------|------------|------|
| 음성 녹음 | 말로 전하는 사랑 | 기능 → 감정 치환 |
| AI 텍스트 변환 | AI가 완성하는 우리 아기 첫 번째 책 | 기술 → 가치 치환 |
| 일기 쓰기 | 엄마가 너를 기다리던 시간 | 행위 → 서사 치환 |
| 알림 발송 | 매일 전해지는 따뜻한 질문 | 시스템 → 교감 치환 |
