# 디어베이비 디자인 시스템

## 개요

DearBaby의 디자인 시스템은 **따뜻함(Warmth)**, **부드러움(Softness)**, **감성(Emotional)**을 핵심 가치로 합니다. 기능 전달보다 감정 전달을 우선하며, 임산부 사용자에게 편안하고 안전한 경험을 제공합니다.

## 디자인 원칙

| 원칙 | 설명 |
|------|------|
| **따뜻함 (Warmth)** | 차갑지 않은 크림·베이지 톤 기반. 그레이 대신 브라운 계열 사용 |
| **부드러움 (Softness)** | 전체적으로 큰 라운드(16-24px). 날카로운 모서리 없음 |
| **여백 (Breathing Space)** | 카드 간 최소 16px 간격. 콘텐츠 밀도보다 편안함 우선 |
| **감성 (Emotional)** | 기능 전달보다 감정 전달 중심의 카피라이팅과 일러스트 |
| **일관성 (Consistency)** | 아이콘은 항상 원형 배경 위에. 카드는 항상 동일 radius·shadow |
