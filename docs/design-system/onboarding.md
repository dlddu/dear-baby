# Onboarding — 점진적 공개 온보딩

## 개요

한 번에 모든 걸 보여주지 않습니다. 사용자의 행동에 따라, 필요한 순간에, 따뜻하게 안내합니다. 시간 기반(Day 1, Day 3)이 아닌 **행동 기반 트리거**로 다음 단계를 엽니다.

## 핵심 원칙

| 원칙 | 설명 |
|------|------|
| **🎯 행동 기반 트리거** | 시간이 아닌 사용자의 행동(첫 기록, N번째 기록)이 다음 단계를 열어줍니다 |
| **💛 감성 톤 일관성** | "설정하세요" 대신 "아기를 만날 날을 알려주세요"처럼 감정 언어를 유지합니다 |
| **✨ 최소 허들 원칙** | 각 단계에서 딱 하나의 입력만 요청하여 이탈을 최소화합니다 |

## Stage 1 — 감성 웰컴 + 예정일 입력

**트리거**: 앱 최초 진입

### 화면 구성

```
┌─────────────────────────┐
│                         │
│       DearBaby          │  ← 로고 (Serif)
│                         │
│   반가워요, 엄마 🌷      │  ← 감성 인사말
│   아기를 기다리는 소중한   │
│   시간, 함께 기록해볼까요? │
│                         │
│  ┌───────────────────┐  │
│  │ 아기를 만날 예정일을 │  │  ← 유일한 입력 필드
│  │ 알려주세요          │  │
│  │ [2025년 9월 15일]   │  │
│  └───────────────────┘  │
│                         │
│     [ 시작하기 ]         │  ← Primary CTA
│   아직 정해지지 않았어요  │  ← 탈출구
│                         │
└─────────────────────────┘
```

### 목표

예정일 **하나만** 받고 즉시 홈에 진입시킵니다. 프로필 사진, 닉네임, 태교 방법 등의 추가 정보는 이 시점에 요구하지 않습니다.

### 카피라이팅 원칙

기능적 표현을 감성적 표현으로 치환합니다.

| ✗ Don't | ✓ Do |
|---------|------|
| 출산 예정일을 입력하세요 | 아기를 만날 날을 알려주세요 |
| 프로필 설정 | (이 단계에서 요구하지 않음) |

### 탈출구 제공

"아직 정해지지 않았어요" 옵션으로 예정일 미정인 사용자도 진입 가능. 입력 허들을 제로에 가깝게 낮춥니다.

---

> 홈 진입 → 첫 번째 질문이 이미 준비됨

## Stage 2 — 첫 기록 유도 + AI 미리보기

**트리거**: 첫 번째 기록 완료 시

### 화면 구성

```
┌─────────────────────────┐
│ ┌─────────────────────┐ │
│ │ 🎙 말하기만 해도      │ │  ← 코치마크 (1회만 표시)
│ │ 기록이 돼요!          │ │
│ └──────────▼──────────┘ │
│                         │
│  ┌───────────────────┐  │
│  │ [임신 17주 3일]     │  │  ← Context Badge
│  │                    │  │
│  │ 오늘 아기에게 가장   │  │  ← 질문 텍스트
│  │ 해주고 싶은 말은?    │  │
│  │                    │  │
│  │ 첫 기록이 가장       │  │  ← Soft Encouragement
│  │ 소중해요 🌱          │  │
│  └───────────────────┘  │
│                         │
│  [🎙 음성 기록] [✏️ 텍스트]│  ← Dual CTA
│                         │
│  ┌───────────────────┐  │
│  │ ✨ AI 미리보기       │  │
│  │ ░░░░░░░░░░░░░░░░░ │  │  ← 블러 처리 (기록 전)
│  │ ░ 엄마가 너를 처음 ░ │  │
│  └───────────────────┘  │
└─────────────────────────┘
```

### 목표

첫 기록을 완료하게 만드는 것이 이 단계의 **유일한 목표**입니다. 코치마크로 음성 기록의 편리함을 강조하고, AI 미리보기를 블러 처리하여 호기심을 유발합니다.

### AI 가치 티저

기록 완료 전에는 AI 편집 결과를 **블러로 가려두고**, 완료 직후 "AI가 이렇게 정리해줄 거예요"라는 미리보기를 보여줍니다. 결과물의 가치를 경험하게 하여 지속 기록 동기를 부여합니다.

Stage 2와 Stage 3의 AI 기능은 별도의 저장소/파이프라인으로 운영합니다. 경계는 [AI Preview — Stage 2 vs Stage 3 boundaries](../engineering/ai-preview-scopes.md)를 참고하세요.

`#호기심유발` `#가치선경험`

### 코치마크 규칙

- 한 화면에 **1개만** 표시
- 닫기 후 **다시 표시하지 않음**
- 툴팁 화살표로 **정확한 대상 요소**를 가리킴

---

> 기록 3~5개 축적 시

## Stage 3 — AI 서사 완성 + 책 제작 안내

**트리거**: 기록 3~5개 도달 시

### 화면 구성

```
┌─────────────────────────┐
│  ┌───────────────────┐  │
│  │ ✨ AI가 완성한       │  │
│  │ 우리 아기 이야기     │  │
│  │                    │  │
│  │ ┃ 3월의 어느 따뜻한  │  │  ← AI 편집 결과 (블러 해제)
│  │ ┃ 오후, 엄마는 처음  │  │
│  │ ┃ 으로 너의 작은     │  │
│  │ ┃ 움직임을 느꼈어... │  │
│  └───────────────────┘  │
│                         │
│  지금까지 5개의 기록이    │  ← 진행 카운터
│  모였어요                │
│                         │
│  ┌───────────────────┐  │
│  │    ┌────────┐      │  │
│  │    │DearBaby│      │  │  ← 책 시각화
│  │    └────────┘      │  │
│  │  세상에 하나뿐인 책  │  │
│  │  기록을 실물 책으로   │  │
│  │  만들 수 있어요 📖   │  │
│  └───────────────────┘  │
│                         │
│     [ 책 미리보기 ]      │  ← CTA
└─────────────────────────┘
```

### 목표

축적된 기록의 가치를 AI 편집본으로 보여주고, 최종 산출물(실물 책)로의 전환을 안내합니다. **달성감**과 함께 자연스럽게 유료 기능을 노출합니다.

### 물리적 산출물 연결

디지털 기록 → AI 편집 → 실물 책이라는 가치 파이프라인의 최종 단계입니다. 책 미리보기를 통해 결과물의 품질을 미리 확인할 수 있습니다.

`#가치전환` `#자연스러운업셀` `#달성감`

### 카운터 활용

"지금까지 N개의 기록이 모였어요"로 진행 상황을 시각화합니다. 기록이 쌓일수록 "책이 더 풍성해져요"라는 메시지로 지속 기록을 유도합니다.

## 전체 온보딩 흐름

```
👋 웰컴 → 📅 예정일 입력 → 🎙 첫 기록 → ✨ AI 미리보기 → 📖 책 제작 안내
(최초 진입)   (1개 입력)    (코치마크)    (첫 기록 완료)    (기록 3~5개)
```

## Do & Don't

### 입력 허들

| ✗ Don't | ✓ Do |
|---------|------|
| 첫 진입에서 프로필, 관심사, 알림 설정 등 여러 단계를 한꺼번에 요구 | 예정일 하나만 받고 즉시 홈에 진입. 나머지는 사용 흐름 속에서 수집 |
| ~~이름, 프로필 사진, 태교 관심사, 알림 시간을 설정해주세요 (4단계)~~ | 아기를 만날 날을 알려주세요 → 바로 홈 |

### 튜토리얼 방식

| ✗ Don't | ✓ Do |
|---------|------|
| 스와이프 튜토리얼로 기능을 나열식으로 설명 | 실제 사용 맥락에서 코치마크 1개로 해당 기능만 안내 |
| ~~기능 1 → 기능 2 → 기능 3 → 기능 4 (건너뛰기)~~ | 🎙 말하기만 해도 기록이 돼요! (첫 홈 진입 시) |

### 트리거 방식

| ✗ Don't | ✓ Do |
|---------|------|
| 시간 기반 트리거 (Day 1, Day 3, Day 7) | 행동 기반 트리거 (첫 기록, N번째 기록) |
| ~~3일 후 → 알림: "아직 기록하지 않으셨어요!"~~ | 첫 기록 완료 → AI 미리보기 자연스럽게 노출 |

### 카피라이팅

| ✗ Don't | ✓ Do |
|---------|------|
| 기능 중심의 딱딱한 안내 카피 | 감정 중심의 따뜻한 안내 카피 |
| ~~음성 인식 기능을 사용해보세요~~ | 아기에게 하고 싶은 말을 들려주세요 🌷 |
